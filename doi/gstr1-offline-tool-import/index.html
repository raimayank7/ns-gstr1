GSTR-1 टेबलआखरी तरीक

GSTR-1 › ऑफलाइन टूल इम्पोर्ट

GST ऑफलाइन टूल च इम्पोर्ट करो ते GSTR-1 फाइल करो

GST पोर्टल Excel सीधा नेईं लैंदा। उदा मुफ्त Returns Offline Tool Excel जां CSV फाइलां पढ़ियै JSON फाइल बनांदा ऐ, ते उसी JSON गी तुस अपलोड करदे ओ। मेकर दियां फाइलां थमां फाइल होए दे रिटर्न तगर दा सारा रस्ता इत्थें ऐ।

इक बारी: ऑफलाइन टूल लैओ

  1. www.gst.gov.in पर Downloads › Offline Tools › Returns Offline Tool च जाइयै उसी डाउनलोड करो (एह् पेज लिखदे बेल्लै, 4 नवंबर 2026 गी, वर्शन 3.2.4)।
  2. जिप खोह्लो ते GST Offline Tool इंस्टॉल करो। एह् सिर्फ Windows पर चलदा ऐ। जिप च सरकारी Excel टेम्पलेट ते नमूने दियां CSV फाइलां बी होंदियां न।

हर म्हीने: JSON बनाओ

  1. GSTR-1 मेकर च बिज़नेस ते मुद्दत चुनो ते Excel वर्कबुक (सारे टेबल) दबाओ। (जां हर टेबल दी अलग फाइल चाहिदी होऐ तां सारियां CSV फाइलां।)
  2. ऑफलाइन टूल खोह्लो, New चुनो, GSTR-1 चुनो, अपना GSTIN, माली साल ते टैक्स मुद्दत लिखो ते Proceed दबाओ।
  3. Import Files दबाओ। वर्कबुक आस्तै Import Excel बरतो; CSV आस्तै हिस्सा (जनेह् B2B) चुनो ते Import CSV बरतो।
  4. View Summary दबाओ ते कुल आंकड़े मेकर दियां टाइलें कन्नै मेलो। टूल रेट ते टैक्सेबल वैल्यू थमां टैक्स कड्ढदा ऐ; जेकर तुंदे बिल पर होर रकम ऐ तां टैक्स दी रकम तुस बदली सकदे ओ।
  5. जेह्ड़ा फाइलां च नेईं आई सकदा, ओह् जोड़ो: एक्सपोर्ट आस्तै पोर्ट कोड ते शिपिंग बिल, ते दित्ते दे डॉक्यूमेंट ते निल रेटेड टेबल जेकर टूल ने इम्पोर्ट नेईं कीते (उदी हेल्प शीट मताबक एह् दो हत्थें लिखने पै सकदे न)।
  6. Generate File दबाओ। टूल तुंदे कंप्यूटर पर JSON फाइल सेव करदा ऐ।

GST पोर्टल पर: अपलोड करो ते फाइल करो

  1. लॉगिन करो, Services › Returns › Returns Dashboard च जाओ, साल ते मुद्दत चुनो।
  2. GSTR-1 टाइल च Prepare Offline, फिरी Upload चुनो ते JSON फाइल चुनो। स्टेटस “processed” होने तगर उडीको। जेकर एरर दिक्खन तां एरर फाइल डाउनलोड करो, ऑफलाइन टूल च खोह्लो, ठीक करो ते फिरी अपलोड करो।
  3. पिच्छें जाओ, Prepare Online चुनो ते हर टेबल चैक करो। IRP पर रजिस्टर कीते दे ई-इनवॉइस इत्थें अपने आप दिक्खदे न।
  4. Generate GSTR-1 Summary दबाओ, चैक करो, फिरी DSC जां EVC (OTP) कन्नै File Statement करो।

लोक कुत्थें अटकदे न

  • ई-इनवॉइस दो बारी अपलोड। जेकर तुस ई-इनवॉइसिंग बरतदे ओ तां ओह् बिल IRP थमां पैह्लें गै GSTR-1 च आई गेदे होंदे न। उसी इनवॉइस नंबर गी फिरी अपलोड करने पर एंट्री बदली जंदी ऐ; अपने आप भरी दी एंट्री फिरी जोड़ने दी थाहर उनेंगी चैक करो।
  • तरीकां। टूल गी DD-MMM-YYYY (05-Nov-2026) चाहिदा। मेकर तरीकां इय्यां गै लिखदा ऐ; Excel च बदलाव करदे बेल्लै सेल टेक्स्ट दे तौर पर गै रक्खो।
  • राज्य। प्लेस ऑफ सप्लाई टूल दी लिस्ट मताबक गै "03-Punjab" इय्यां लिखना चाहिदा।
  • पुराना टेम्पलेट। जेकर ऑफलाइन टूल दा अग्गला वर्शन नमां टेम्पलेट मंगै तां साढ़ी वर्कबुक दियां लैनां नमें टेम्पलेट दी उसी नांऽ आली शीट च कॉपी करो।
  • होर सॉफ्टवेयर दे बिल। मेकर सिर्फ Nivesh Sahayak च सेव कीते दे बिलें गी जानदा ऐ। JSON बनाने कोला पैह्लें होर बिल ऑफलाइन टूल च जोड़ो।
इस म्हीने दे बिल हुन्नै गै GSTR-1 च थाहर लाओ।मेकर खोह्लो
