ଆପଣଙ୍କ ବିଲ୍‌ରୁ ମାଗଣା GSTR-1 ସାରାଂଶ

ଆପଣଙ୍କ ବିଜନେସ୍ ଓ ମାସ ବାଛନ୍ତୁ। Nivesh Sahayak ର ଡକ୍ୟୁମେଣ୍ଟ ସାଇଟ୍‌ଗୁଡ଼ିକରେ ଆପଣ ସେଭ୍ କରିଥିବା ସମସ୍ତ GST ବିଲ୍ ଓ କ୍ରେଡିଟ୍ ନୋଟ୍ GSTR-1 ର ଟେବୁଲ୍‌ରେ ସଜାଯିବ, ସାଙ୍ଗକୁ ମୋଟ ଅଙ୍କ, ଚେତାବନୀ ଓ GST Returns Offline Tool ପାଇଁ ପ୍ରସ୍ତୁତ ଫାଇଲ୍। ଲଗଇନ୍ ଦରକାର ନାହିଁ, କିଛି ଅପଲୋଡ୍ ହୁଏ ନାହିଁ।

ଏଠାରେ GSTR-1 ସାରାଂଶ କିପରି ବନାଇବେ

  1. ପ୍ରଥମେ ଏଠାରେ ବିଲ୍ ବନାନ୍ତୁ। billing.niveshsahayak.in ରେ ଟ୍ୟାକ୍ସ ଇନଭଏସ୍, GST ସହିତ କ୍ୟାସ୍ ମେମୋ, ଓ credit-note.niveshsahayak.in ରେ କ୍ରେଡିଟ୍ ବା ଡେବିଟ୍ ନୋଟ୍ ଏହି ବ୍ରାଉଜରରେ ସେଭ୍ ହୁଏ। ଏହି ପେଜ୍ ସେଗୁଡ଼ିକୁ ପଢ଼ି ନିଏ; ଆପଣଙ୍କୁ ପୁଣି କିଛି ଟାଇପ୍ କରିବାକୁ ପଡ଼େ ନାହିଁ।
  2. ବିଜନେସ୍ ଓ ସମୟ ବାଛନ୍ତୁ। ଏକ ମାସ ବାଛନ୍ତୁ, ବା QRMP ସ୍କିମ୍‌ରେ ଥିଲେ ଏକ କ୍ୱାର୍ଟର୍। ଟର୍ନଓଭରର ଘରଟି ମଧ୍ୟ ବାଛନ୍ତୁ, ଯେପରି HSN କୋଡ୍‌ରେ ଠିକ୍ କେତେ ଅଙ୍କ ଅଛି ତାହା ଯାଞ୍ଚ ହେବ।
  3. ଚେତାବନୀଗୁଡ଼ିକ ପଢନ୍ତୁ। HSN କୋଡ୍ ନଥିବା, କ୍ରେତାଙ୍କର ଭୁଲ GSTIN, ନମ୍ବର ସିରିଜ୍‌ରେ ଫାଙ୍କ, ଆଉ ଯେଉଁ ନୋଟ୍‌ର ମୂଳ ଇନଭଏସ୍ ସେଭ୍ ହୋଇନାହିଁ, ଏସବୁ ଉପରେ ଦେଖାଯାଏ। ବିଲ୍‌ଗୁଡ଼ିକୁ ସେମାନଙ୍କ ନିଜ ସାଇଟ୍‌ରେ ଠିକ୍ କରନ୍ତୁ, ତା’ପରେ ସେଭ୍ ହୋଇଥିବା ବିଲ୍ ପୁଣି ପଢନ୍ତୁ ଦବାନ୍ତୁ।
  4. ପ୍ରତ୍ୟେକ ଟେବୁଲ୍ ଦେଖନ୍ତୁ। B2B ବିଲ୍ GSTIN ସହିତ ଗୋଟି ଗୋଟି କରି ଥାଏ; ଛୋଟ B2C ବିକ୍ରି ରାଜ୍ୟ ଓ ରେଟ୍ ଅନୁସାରେ ଯୋଡ଼ାଯାଏ; HSN ସାରାଂଶ ଏବେ ପୋର୍ଟାଲ୍ ଯେପରି ଚାହେଁ ସେପରି B2B ଓ B2C ରେ ବିଭକ୍ତ।
  5. ଫାଇଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ। Excel ୱାର୍କବୁକ୍ (ସବୁ ଟେବୁଲ୍) ଅଫଲାଇନ୍ ଟୁଲ୍‌ର ସିଟ୍ ନାମ ସହିତ ଗୋଟିଏ ଫାଇଲ୍ ଦିଏ; ସବୁ CSV ଫାଇଲ୍ ପ୍ରତ୍ୟେକ ଟେବୁଲ୍ ପାଇଁ ଟୁଲ୍‌ର ନିଜ ହେଡର୍ ସହିତ ଗୋଟିଏ ଗୋଟିଏ ଫାଇଲ୍ ଦିଏ।
  6. JSON ବନାଇ ଫାଇଲ୍ କରନ୍ତୁ। ଫାଇଲ୍‌ଗୁଡ଼ିକୁ GST Returns Offline Tool ରେ ଇମ୍ପୋର୍ଟ କରନ୍ତୁ, JSON ବନାନ୍ତୁ, GST ପୋର୍ଟାଲରେ GSTR-1 ରେ ଅପଲୋଡ୍ କରନ୍ତୁ, ସେଠାରେ ସାରାଂଶ ଦେଖି ଫାଇଲ୍ କରନ୍ତୁ। ଦେଖନ୍ତୁ ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଇମ୍ପୋର୍ଟ କରିବା ନିୟମ।

ଏହା ଆପଣଙ୍କ ପାଇଁ କ'ଣ କରେ

  • ପ୍ରତ୍ୟେକ ବିଲ୍ ନିଜେ ସଜାଏ: କ୍ରେତାଙ୍କ GSTIN, ରାଜ୍ୟ ଓ ବିଲ୍ ମୂଲ୍ୟ ଅନୁସାରେ ଟେବୁଲ୍ 4, 5, 6A, 7, 8, 9B, 11A, 12 ଓ 13 ରେ।
  • B2C Large ର ₹1 ଲକ୍ଷ ସୀମା ବ୍ୟବହାର କରେ ଅଗଷ୍ଟ 2024 ପିରିୟଡ୍‌ରୁ ପରବର୍ତ୍ତୀ ବିଲ୍ ପାଇଁ, ଆଉ ପୁରୁଣା ବିଲ୍ ପାଇଁ ଆଗର ₹2.5 ଲକ୍ଷ।
  • କ୍ରେଡିଟ୍ ଓ ଡେବିଟ୍ ନୋଟ୍ ସମ୍ଭାଳେ: ରେଜିଷ୍ଟର୍ଡ୍ କ୍ରେତାଙ୍କ ନୋଟ୍ 9B କୁ ଯାଏ, ଆଉ ଛୋଟ B2C ବିଲ୍‌ର ନୋଟ୍ ରିଟର୍ଣ୍ଣ ନିୟମ ଅନୁସାରେ B2CS ଅଙ୍କ କମାଏ ବା ବଢ଼ାଏ।
  • HSN ସାରାଂଶ ଦୁଇ ଭାଗରେ, B2B ଓ B2C, ପୋର୍ଟାଲ୍ ମାନୁଥିବା ରେଟ୍, ପରିମାଣ ଓ ୟୁନିଟ୍ କୋଡ୍ (UQC) ସହିତ; ସର୍ଭିସ୍‌ରେ (SAC 99…) ପରିମାଣ ବସେ ନାହିଁ।
  • ଜାରି ହୋଇଥିବା ଡକ୍ୟୁମେଣ୍ଟ (ଟେବୁଲ୍ 13): ପ୍ରତ୍ୟେକ ନମ୍ବର ସିରିଜ୍‌ର ପ୍ରଥମ ଓ ଶେଷ ନମ୍ବର ଓ ମୋଟ ସଂଖ୍ୟା, ନମ୍ବର ବାଦ୍ ପଡ଼ିଲେ ବା ଦୁଇଥର ଥିଲେ ଚେତାବନୀ ସହିତ।
  • ଅଫଲାଇନ୍ ଟୁଲ୍‌ର ଲେଆଉଟ୍: GST Returns Offline Tool V3.2.4 ର ଫାଇଲ୍‌ରୁ ହେଡର୍ ନିଆଯାଇଛି, ତାରିଖ DD-MMM-YYYY ଓ ରାଜ୍ୟ "07-Delhi" ଢଙ୍ଗରେ।

ଆପଣଙ୍କ ଡାଟା ଆପଣଙ୍କ ପାଖରେ ହିଁ ରହେ

ସାରାଂଶ ଏହି ବ୍ରାଉଜରରେ ହିଁ ହିସାବ ହୁଏ, ଆପଣଙ୍କ Nivesh Sahayak ଡାଟା ହୋମ୍‌ରେ (my.niveshsahayak.in) ସେଭ୍ ହୋଇଥିବା ବିଲ୍‌ରୁ। ଆମକୁ ବା GST ପୋର୍ଟାଲକୁ କିଛି ପଠାଯାଏ ନାହିଁ। ରିଟର୍ଣ୍ଣ ଆପଣ ନିଜେ, ନିଜ ଲଗଇନ୍‌ରେ ଅପଲୋଡ୍ କରିବେ।

ଫାଇଲ୍ କରିବା ପୂର୍ବରୁ ଯାଞ୍ଚ କରନ୍ତୁ। ଏହା ଆପଣଙ୍କ ନିଜ ବିଲ୍‌ରୁ ବନାଯାଇଥିବା ଏକ ୱାର୍କିଂ ସିଟ୍। ଅନ୍ୟ ସଫ୍ଟୱେୟାରରେ ବନାଯାଇଥିବା ବିଲ୍, ବାତିଲ୍ ବିଲ୍ ଓ ଆଗ ମାସର ସଂଶୋଧନ ଏଥିରେ ନାହିଁ। ଆପଣଙ୍କ GSTR-1 ର ଦାୟିତ୍ୱ ଆପଣଙ୍କର; ସନ୍ଦେହ ହେଲେ ଆକାଉଣ୍ଟାଣ୍ଟଙ୍କୁ ପଚାରନ୍ତୁ।

ଗାଇଡ୍

GSTR-1 ଟେବୁଲ୍ ବୁଝନ୍ତୁକେଉଁ ବିଲ୍ କେଉଁ ଟେବୁଲ୍‌କୁ ଯାଏ, ଉଦାହରଣ ସହିତ। GSTR-1 ଶେଷ ତାରିଖ ଓ QRMPମାସିକ, ତ୍ରୈମାସିକ, IFF, GSTR-1A ଓ ତିନି ବର୍ଷର ସୀମା। HSN ସାରାଂଶ (ଟେବୁଲ୍ 12)କେତେ ଅଙ୍କ, B2B ଓ B2C ଭାଗ, UQC ଓ ସାଧାରଣ ଭୁଲ। GST ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଇମ୍ପୋର୍ଟExcel ବା CSV ରୁ ଫାଇଲ୍ ହୋଇଥିବା GSTR-1 ପର୍ଯ୍ୟନ୍ତ।

ଲୋକେ ଯାହା ପଚାରନ୍ତି

ଏହା କ'ଣ ମୋ GSTR-1 ଫାଇଲ୍ କରିଦିଏ?

ନା। ଏହା କେବଳ ହିସାବ ଓ ଫାଇଲ୍ ବନାଏ। ଆପଣ ସେଗୁଡ଼ିକୁ ମାଗଣା GST ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଇମ୍ପୋର୍ଟ କରିବେ, ନିଜ ଲଗଇନ୍‌ରେ GST ପୋର୍ଟାଲରେ JSON ଅପଲୋଡ୍ କରିବେ ଓ ସେଠାରେ ହିଁ ଫାଇଲ୍ କରିବେ।

ବିଲ୍ କେଉଁଠାରୁ ଆସେ?

Nivesh Sahayak ର ଡକ୍ୟୁମେଣ୍ଟ ସାଇଟ୍‌ଗୁଡ଼ିକ (ବିଲିଂ, କ୍ୟାସ୍ ମେମୋ, କ୍ରେଡିଟ୍ ନୋଟ୍, ରସିଦ୍ ଇତ୍ୟାଦି) ଏହି ବ୍ରାଉଜରରେ ଯାହା ସେଭ୍ କରିଛନ୍ତି, ସେଠାରୁ। ଅନ୍ୟ ସଫ୍ଟୱେୟାରର ବିଲ୍ ଏଥିରେ ନଥାଏ।

JSON ଡାଉନଲୋଡ୍ କାହିଁକି ନାହିଁ?

GST ପୋର୍ଟାଲର JSON ଫର୍ମାଟ୍ ସମୟ ସମୟରେ ବଦଳେ, ଆଉ କେବଳ ସରକାରୀ ଅଫଲାଇନ୍ ଟୁଲ୍ ହିଁ ନିଶ୍ଚିତ ଭାବେ ତାହା ସହ ମେଳ ଖାଏ। ତେଣୁ ଆମେ ଅଫଲାଇନ୍ ଟୁଲ୍‌ର ନିଜ ଲେଆଉଟ୍‌ରେ Excel ଓ CSV ଦେଉ, ଆଉ JSON ଟୁଲ୍ ନିଜେ ବନାଏ।

କେଉଁ ବିଲ୍ B2C Large କୁ ଯାଏ?

ଅନ୍ୟ ରାଜ୍ୟର ଅନ୍‌ରେଜିଷ୍ଟର୍ଡ୍ କ୍ରେତାଙ୍କୁ ଦିଆଯାଇଥିବା, ₹1 ଲକ୍ଷରୁ ଅଧିକ ମୂଲ୍ୟର ବିଲ୍ (ଅଗଷ୍ଟ 2024 ପିରିୟଡ୍‌ରୁ; ଆଗରୁ ₹2.5 ଲକ୍ଷ ଥିଲା)। ଅନ୍ୟ ସମସ୍ତ B2C ବିଲ୍ B2C Small ରେ ଯୋଡ଼ାଯାଏ।

ତ୍ରୈମାସିକ ରିଟର୍ଣ୍ଣ ପାଇଁ ବ୍ୟବହାର କରିହେବ କି?

ହଁ। “ଏକ କ୍ୱାର୍ଟର୍ (QRMP)” ବାଛନ୍ତୁ ଓ କ୍ୱାର୍ଟରର ଯେକୌଣସି ଗୋଟିଏ ମାସ ଦିଅନ୍ତୁ; ତିନି ମାସ ଏକାଠି ଧରାଯିବ।

ଏହା ମାଗଣା କି?

ହଁ, ପୂରା ମାଗଣା। ଲଗଇନ୍ ଦରକାର ନାହିଁ, ବିଲ୍ ସଂଖ୍ୟାର ମଧ୍ୟ ସୀମା ନାହିଁ।
