GSTR-1 › ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଇମ୍ପୋର୍ଟ

GST ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଇମ୍ପୋର୍ଟ କରି GSTR-1 ଫାଇଲ୍ କରନ୍ତୁ

GST ପୋର୍ଟାଲ୍ ସିଧାସଳଖ Excel ନିଏ ନାହିଁ। ତାହାର ମାଗଣା Returns Offline Tool Excel ବା CSV ଫାଇଲ୍ ପଢ଼ି JSON ଫାଇଲ୍ ବନାଏ, ଆଉ ଅପଲୋଡ୍ କରିବାକୁ ହୁଏ ସେହି JSON। ମେକର୍‌ର ଫାଇଲ୍‌ରୁ ଫାଇଲ୍ ହୋଇଥିବା ରିଟର୍ଣ୍ଣ ପର୍ଯ୍ୟନ୍ତ ପୂରା ବାଟ ଏଠାରେ ଅଛି।

ଥରେ: ଅଫଲାଇନ୍ ଟୁଲ୍ ନିଅନ୍ତୁ

  1. www.gst.gov.in ରେ ଯାଇ Downloads › Offline Tools › Returns Offline Tool ଖୋଲି ଡାଉନଲୋଡ୍ କରନ୍ତୁ (ଏହି ପେଜ୍ ଲେଖିବା ବେଳେ, 4 ନଭେମ୍ବର 2026 ରେ, ଭର୍ସନ୍ 3.2.4 ଥିଲା)।
  2. ଜିପ୍ ଖୋଲି GST Offline Tool ଇନଷ୍ଟଲ୍ କରନ୍ତୁ। ଏହା କେବଳ Windows ରେ ଚାଲେ। ଜିପ୍‌ରେ ସରକାରୀ Excel ଟେମ୍ପଲେଟ୍ ଓ ନମୁନା CSV ଫାଇଲ୍ ମଧ୍ୟ ଥାଏ।

ପ୍ରତି ମାସ: JSON ବନାନ୍ତୁ

  1. GSTR-1 ମେକର୍‌ରେ ବିଜନେସ୍ ଓ ପିରିୟଡ୍ ବାଛି Excel ୱାର୍କବୁକ୍ (ସବୁ ଟେବୁଲ୍) ଦବାନ୍ତୁ। (ବା ପ୍ରତି ଟେବୁଲ୍‌ର ଗୋଟିଏ ଫାଇଲ୍ ପାଇଁ ସବୁ CSV ଫାଇଲ୍।)
  2. ଅଫଲାଇନ୍ ଟୁଲ୍ ଖୋଲି New ବାଛନ୍ତୁ, GSTR-1 ବାଛନ୍ତୁ, ଆପଣଙ୍କ GSTIN, ଆର୍ଥିକ ବର୍ଷ ଓ ଟ୍ୟାକ୍ସ ପିରିୟଡ୍ ଲେଖି Proceed ଦବାନ୍ତୁ।
  3. Import Files ଦବାନ୍ତୁ। ୱାର୍କବୁକ୍ ପାଇଁ Import Excel; CSV ହେଲେ ସେକ୍ସନ୍ (ଯେପରି B2B) ବାଛି Import CSV ବ୍ୟବହାର କରନ୍ତୁ।
  4. View Summary ଦବାନ୍ତୁ ଓ ମୋଟ ଅଙ୍କଗୁଡ଼ିକୁ ମେକର୍‌ର ଟାଇଲ୍ ସହ ମିଳାଇ ଦେଖନ୍ତୁ। ଟୁଲ୍ ରେଟ୍ ଓ ଟ୍ୟାକ୍ସେବଲ୍ ଭ୍ୟାଲୁରୁ ଟ୍ୟାକ୍ସ ହିସାବ କରେ; ଆପଣଙ୍କ ବିଲ୍‌ରେ ଅଲଗା ଅଙ୍କ ଥିଲେ ଟ୍ୟାକ୍ସ ଅଙ୍କ ବଦଳାଇପାରିବେ।
  5. ଫାଇଲ୍ ଯାହା ବହନ କରିପାରେ ନାହିଁ ତାହା ଯୋଡନ୍ତୁ: ଏକ୍ସପୋର୍ଟ ପାଇଁ ପୋର୍ଟ କୋଡ୍ ଓ ସିପିଂ ବିଲ୍, ଆଉ ଜାରି ହୋଇଥିବା ଡକ୍ୟୁମେଣ୍ଟ ଓ ନିଲ୍ ରେଟେଡ୍ ଟେବୁଲ୍ ଯଦି ଟୁଲ୍ ଇମ୍ପୋର୍ଟ କରିନାହିଁ (ଟୁଲ୍‌ର ହେଲ୍ପ ସିଟ୍ କହେ ଏହି ଦୁଇଟି ହାତରେ ଲେଖିବାକୁ ପଡ଼ିପାରେ)।
  6. Generate File ଦବାନ୍ତୁ। ଟୁଲ୍ ଆପଣଙ୍କ କମ୍ପ୍ୟୁଟରରେ ଏକ JSON ଫାଇଲ୍ ସେଭ୍ କରେ।

GST ପୋର୍ଟାଲରେ: ଅପଲୋଡ୍ ଓ ଫାଇଲ୍

  1. ଲଗଇନ୍ କରି Services › Returns › Returns Dashboard କୁ ଯାଆନ୍ତୁ, ବର୍ଷ ଓ ପିରିୟଡ୍ ବାଛନ୍ତୁ।
  2. GSTR-1 ଟାଇଲ୍‌ରେ Prepare Offline ବାଛି Upload ଦବାନ୍ତୁ ଓ JSON ଫାଇଲ୍ ଦିଅନ୍ତୁ। ଷ୍ଟାଟସ୍‌ରେ ପ୍ରୋସେସ୍ ହେଲା ବୋଲି ନଆସିବା ଯାଏ ଅପେକ୍ଷା କରନ୍ତୁ। ଭୁଲ ଦେଖାଇଲେ ଏରର ଫାଇଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ, ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଖୋଲି ଠିକ୍ କରି ପୁଣି ଅପଲୋଡ୍ କରନ୍ତୁ।
  3. ଫେରି ଆସି Prepare Online ବାଛି ପ୍ରତ୍ୟେକ ଟେବୁଲ୍ ଦେଖନ୍ତୁ। IRP ରେ ଆପଣ ରେଜିଷ୍ଟର୍ କରିଥିବା e-invoice ଏଠାରେ ନିଜେ ଆସିଯାଏ।
  4. Generate GSTR-1 Summary ଦବାନ୍ତୁ, ଦେଖିନିଅନ୍ତୁ, ତା’ପରେ DSC ବା EVC (OTP) ରେ File Statement କରନ୍ତୁ।

ଯେଉଁଠି ଲୋକେ ଅଟକିଯାଆନ୍ତି

  • e-invoice ଦୁଇଥର ଅପଲୋଡ୍। e-invoicing କଲେ ସେହି ବିଲ୍ IRP ରୁ ଆଗରୁ GSTR-1 ରେ ଅଛି। ସମାନ ଇନଭଏସ୍ ନମ୍ବର ପୁଣି ଅପଲୋଡ୍ କଲେ ଏଣ୍ଟ୍ରି ବଦଳିଯାଏ; ନିଜେ ପୁଣି ଯୋଡ଼ିବା ବଦଳରେ ଅଟୋ-ଭରା ଏଣ୍ଟ୍ରିଗୁଡ଼ିକ ଦେଖିନିଅନ୍ତୁ।
  • ତାରିଖ। ଟୁଲ୍ ଚାହେଁ DD-MMM-YYYY (05-Nov-2026)। ମେକର୍ ଏହିପରି ତାରିଖ ଲେଖେ; Excel ରେ ବଦଳାଇଲେ ଘରଗୁଡ଼ିକୁ ଟେକ୍ସଟ୍ ରଖନ୍ତୁ।
  • ରାଜ୍ୟ। ପ୍ଲେସ୍ ଅଫ୍ ସପ୍ଲାଇ "03-Punjab" ଢଙ୍ଗରେ ଲେଖିବାକୁ ହେବ, ଟୁଲ୍‌ର ତାଲିକାରେ ଯେପରି ଅଛି ଠିକ୍ ସେପରି।
  • ପୁରୁଣା ଟେମ୍ପଲେଟ୍। ଅଫଲାଇନ୍ ଟୁଲ୍‌ର ଭବିଷ୍ୟତ ଭର୍ସନ୍ ନୂଆ ଟେମ୍ପଲେଟ୍ ଚାହିଁଲେ ଆମ ୱାର୍କବୁକ୍‌ର ଧାଡ଼ିଗୁଡ଼ିକୁ ସମାନ ନାମର ସିଟ୍‌ରେ ନୂଆ ଟେମ୍ପଲେଟ୍‌କୁ କପି କରନ୍ତୁ।
  • ଅନ୍ୟ ସଫ୍ଟୱେୟାରର ବିଲ୍। ମେକର୍ କେବଳ Nivesh Sahayak ରେ ସେଭ୍ ହୋଇଥିବା ବିଲ୍ ଚିହ୍ନେ। JSON ବନାଇବା ପୂର୍ବରୁ ଅନ୍ୟ ବିଲ୍ ଅଫଲାଇନ୍ ଟୁଲ୍‌ରେ ଯୋଡନ୍ତୁ।
ଏହି ମାସର ବିଲ୍ ଏବେ ହିଁ GSTR-1 ରେ ସଜାଇ ନିଅନ୍ତୁ।ମେକର୍ ଖୋଲନ୍ତୁ
