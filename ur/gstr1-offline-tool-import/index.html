GSTR-1 › آف لائن ٹول میں امپورٹ

GST آف لائن ٹول میں امپورٹ کریں اور GSTR-1 فائل کریں

GST پورٹل Excel سیدھا نہیں لیتا۔ اس کا مفت Returns Offline Tool Excel یا CSV فائلیں پڑھ کر JSON فائل بناتا ہے، اور وہی JSON آپ اپ لوڈ کرتے ہیں۔ یہ ہے میکر کی فائلوں سے فائل ہوئے ریٹرن تک پورا راستہ۔

ایک بار: آف لائن ٹول لیں

  1. www.gst.gov.in پر Downloads › Offline Tools › Returns Offline Tool میں جا کر اسے ڈاؤن لوڈ کریں (یہ صفحہ لکھتے وقت، 4 نومبر 2026 کو، ورژن 3.2.4 تھا)۔
  2. زپ کھولیں اور GST Offline Tool انسٹال کریں۔ یہ صرف Windows پر چلتا ہے۔ زپ میں سرکاری Excel ٹیمپلیٹ اور نمونے کی CSV فائلیں بھی ہیں۔

ہر مہینے: JSON بنائیں

  1. GSTR-1 میکر میں بزنس اور مدت چنیں اور Excel ورک بک (تمام ٹیبل) دبائیں۔ (یا ہر ٹیبل کی الگ فائل کے لیے تمام CSV فائلیں۔)
  2. آف لائن ٹول کھولیں، New چنیں، GSTR-1 چنیں، اپنا GSTIN، مالی سال اور ٹیکس مدت لکھیں اور Proceed دبائیں۔
  3. Import Files دبائیں۔ ورک بک کے لیے Import Excel استعمال کریں؛ CSV کے لیے سیکشن (مثلاً B2B) چنیں اور Import CSV استعمال کریں۔
  4. View Summary دبائیں اور ٹوٹل کو میکر کے ٹائلز سے ملائیں۔ ٹول ٹیکس ریٹ اور ٹیکسیبل ویلیو سے نکالتا ہے؛ آپ کے بل پر ٹیکس مختلف ہو تو آپ ٹیکس کی رقم بدل سکتے ہیں۔
  5. جو فائلیں نہیں لے جا سکتیں وہ ڈالیں: ایکسپورٹ کے لیے پورٹ کوڈ اور شپنگ بل، اور جاری کیے گئے ڈاکیومنٹ اور نِل ریٹڈ ٹیبل اگر ٹول نے امپورٹ نہ کیے ہوں (اس کی ہیلپ شیٹ کے مطابق ان دونوں کو ہاتھ سے لکھنا پڑ سکتا ہے)۔
  6. Generate File دبائیں۔ ٹول آپ کے کمپیوٹر پر ایک JSON فائل سیو کرتا ہے۔

GST پورٹل پر: اپ لوڈ اور فائل

  1. لاگ اِن کریں، Services › Returns › Returns Dashboard میں جا کر سال اور مدت چنیں۔
  2. GSTR-1 ٹائل میں Prepare Offline چنیں، پھر Upload، اور JSON فائل چنیں۔ اسٹیٹس “processed” آنے تک انتظار کریں۔ ایرر دکھیں تو ایرر فائل ڈاؤن لوڈ کریں، آف لائن ٹول میں کھولیں، ٹھیک کریں اور دوبارہ اپ لوڈ کریں۔
  3. واپس جا کر Prepare Online چنیں اور ہر ٹیبل جانچیں۔ IRP پر رجسٹر کیے ہوئے ای انوائس یہاں پہلے سے خود آ جاتے ہیں۔
  4. Generate GSTR-1 Summary دبائیں، جانچیں، پھر DSC یا EVC (OTP) سے File Statement کریں۔

جہاں لوگ پھنستے ہیں

  • ای انوائس دو بار اپ لوڈ۔ آپ ای انوائسنگ استعمال کرتے ہوں تو وہ بل IRP سے پہلے ہی GSTR-1 میں آ چکے ہوتے ہیں۔ وہی انوائس نمبر دوبارہ اپ لوڈ کرنے سے اندراج بدل جاتا ہے؛ خود بھرے اندراجات کو دوبارہ جوڑنے کی بجائے انہیں جانچیں۔
  • تاریخیں۔ ٹول کو DD-MMM-YYYY (05-Nov-2026) چاہیے۔ میکر تاریخیں اسی طرح لکھتا ہے؛ Excel میں ایڈٹ کریں تو سیلز کو ٹیکسٹ ہی رہنے دیں۔
  • ریاستیں۔ پلیس آف سپلائی بالکل ٹول کی فہرست کی طرح "03-Punjab" لکھی ہونی چاہیے۔
  • پرانا ٹیمپلیٹ۔ آف لائن ٹول کا آنے والا ورژن نیا ٹیمپلیٹ مانگے تو ہماری ورک بک کی قطاریں نئے ٹیمپلیٹ کی انہی ناموں والی شیٹوں میں کاپی کر لیں۔
  • دوسرے سافٹ ویئر کے بل۔ میکر صرف Nivesh Sahayak میں سیو کیے بل جانتا ہے۔ JSON بنانے سے پہلے دوسرے بل آف لائن ٹول میں جوڑیں۔
