GSTR-1 › अफलाइन टुल इम्पर्ट

GST अफलाइन टुलआव इम्पर्ट खालाम आरो GSTR-1 फाइल खालाम

GST पोर्टालआ Excel जोबोद लाखै। बेनि फ्री Returns Offline Tool आ Excel एबा CSV फाइलफोरखौ फरायनानै JSON फाइल बानायो, आरो बे JSON नोंथां आपलोड खालामनांगौ। मेकारनि फाइलनिफ्राय फाइल जानाय रिटार्न सिम गासै लामाखौ बेयाव दं।

मोनसे खेप: अफलाइन टुल मोन

  1. www.gst.gov.in आव Downloads › Offline Tools › Returns Offline Tool आव थां आरो बेखौ डाउनलोड खालाम (बे पेज लिरनाय समायाव, 4 नभेम्बार 2026, भार्सन 3.2.4)।
  2. बेखौ अनजिप खालाम आरो GST Offline Tool इन्स्टल खालाम। बेआ Windows आवनो गोरोबो। zip आव सरकारिया Excel टेम्पलेट आरो नमुना CSV फाइलफोरबो दं।

आफाद आफादआव: JSON बानाय

  1. GSTR-1 मेकारआव बिजिनेस आरो समाया बायनाय आरो Excel वर्कबुक (गासैबो टेबल) थाप। (एबा टेबल मोनसे मोनसेनि फाइलनि थाखाय गासै CSV फाइलफोर।)
  2. अफलाइन टुल खेव, New बायनाय, GSTR-1 बायनाय, नोंथांनि GSTIN, आथिक बसर आरो टेक्स समाया टाइप खालाम आरो Proceed थाप।
  3. Import Files थाप। वर्कबुकनि थाखाय Import Excel बाहाय; CSV नि थाखाय बाहागो (जेरै B2B) बायनाय आरो Import CSV बाहाय।
  4. View Summary थाप आरो जम्मा अंकाफोरखौ मेकारनि टाइलफोरजों गोरोबाय। टुलआ रेट आरो टेक्सेबल भेल्युनिफ्राय टेक्स हिसाब खालायो; नोंथांनि बिलआव गुबुन टेक्सनि दाम दं जायोब्ला नोंथां बेखौ सोलायनो हायो।
  5. फाइलआ मा लानो हायाखै बेखौ मोनथाम: एक्सपर्टनि थाखाय पोर्ट कोड आरो सिपिं बिल, आरो टुलआ इम्पर्ट खालाखै जायोब्ला होनाय डकुमेन्ट आरो निल रेटेड टेबल (बेनि हेल्प सिटआव बे गनां नैथाय हाथजों टाइप खालामनांगौ जाथाय)।
  6. Generate File थाप। टुलआ नोंथांनि कम्पिउटारआव JSON फाइल सेभ खालायो।

GST पोर्टालआव: आपलोड खालाम आरो फाइल खालाम

  1. लगिन खालाम, Services › Returns › Returns Dashboard आव थां, बसर आरो समाया बायनाय।
  2. GSTR-1 टाइलआव Prepare Offline बायनाय, उनाव Upload, आरो JSON फाइल बायनाय। स्टेटासआव "processed" नुजा सिम थाम। भुल नुजाब्ला error file डाउनलोड खालाम, अफलाइन टुलआव खेव, फोरमाय आरो फिन आपलोड खालाम।
  3. सिगां फिन थां, Prepare Online बायनाय आरो टेबल मोनसे मोनसे नाय। IRP आव नोंथां रेजिस्टार खालाबाय इ-इनभइसफोर बेयाव गावनोगाव नुजायो।
  4. Generate GSTR-1 Summary थाप, नाय, उनाव DSC एबा EVC (OTP) जों File Statement खालाम।

मानसिफोरा माव थाव गोख्रै

  • इ-इनभइस नैथाय आपलोड जानाय। इ-इनभइसिं बाहायोब्ला बे बिलफोर IRP निफ्राय सिगांनो GSTR-1 आव दं। बे इनभइस नम्बारखौ फिन आपलोड खालाब्ला एन्ट्रिखौ सोलायो; गावनोगाव फुरायनाय एन्ट्रिफोरखौ फिन मोनथाम होनाय नङा, नाय।
  • तारिख। टुलआ DD-MMM-YYYY (05-Nov-2026) नायो। मेकारआ तारिखफोरखौ बेबादि लिरो; Excel आव सोलायब्ला सेलफोरखौ text बादि थाखिन।
  • राज्य। प्लेस अब सापलाइ "03-Punjab" बादि, टुलनि लिस्टआव जेरैयाव लिरनाय बादि लिरनांगौ।
  • जुनार टेम्पलेट। अफलाइन टुलनि उनावनि भार्सनआ गोदान टेम्पलेट नाबाब्ला जोंनि वर्कबुकनिफ्राय पांक्तिफोरखौ बे मुंजों गोदान टेम्पलेटनि सिटआव कपि खालाम।
  • गुबुन सफ्टवेयारनिफ्राय बिल। मेकारआ Nivesh Sahayak आव सेभ जानाय बिलफोरखौनो सिन्दो। JSON बानायनाय सिगां गुबुन बिलफोरखौ अफलाइन टुलआव मोनथाम।
बे आफादनि बिलफोरखौ दासिमनो GSTR-1 आव फिलिंगा खालाम।मेकार खेव
