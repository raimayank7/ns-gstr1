GSTR-1 टेबलफोरजोबथा तारिख

नोंथांनि बिलनिफ्राय फ्री GSTR-1 सारांस

नोंथांनि बिजिनेस आरो आफादखौ बायनाय। Nivesh Sahayak डकुमेन्ट साइटआव नोंथांनि सेभ खालामनाय गासै GST बिल आरो क्रेडिट नोटफोरखौ GSTR-1 टेबलआव फिलिंगा खालामनाय जादों, जम्मा, सावधान आरो GST Returns Offline Tool नि थाखाय सैखालाम फाइलफोर सोलोंगोन। लगिन गैया, जेबो आपलोड जाया।

बेयाव GSTR-1 सारांस माबोरै बानायनो

  1. सिगां बेयाव नोंथांनि बिलफोर बानाय। billing.niveshsahayak.in आव टेक्स इनभइस, GST सहित केस मेमो, आरो credit-note.niveshsahayak.in आव क्रेडिट एबा डेबिट नोट बे ब्राउजारआव सेभ जायो। बे पेजआ बेफोरखौ फरायो; नोंथांआ फिन जेबो टाइप खालामनाय गैया।
  2. बिजिनेस आरो समाया बायनाय। मोनसे आफाद बायनाय, एबा QRMP स्कीमआव दं जायोब्ला मोनसे क्वार्टार। टार्नओभारनि बिलाइखौ बायनाय, बेनिखायनो HSN कोडनि हांखो हिसाब मोजां नायनाय जायो।
  3. सावधानफोरखौ फरायनाय। HSN कोड गैया, गाहायनि GSTIN बादि गैया, नम्बार सिरिजआव बांखिनाय नम्बार, जोबथा इनभइस सेभ जाया नोटफोर — बेफोरखौ गोजाव लिर थादों। बिलफोरखौ बेनि निजि साइटआव फोरमाय, उनाव सेभ जानाय बिलफोरखौ फिन फराय थाप।
  4. मोनसे मोनसे टेबल नाय। B2B बिलफोर गाहायनि GSTIN सोलोंगाव मोनसे मोनसे लिर जादों; खुबु B2C बिक्रिफोर राज्य आरो रेटनि सावराव फिलिंगा जादों; HSN सारांसखौ पोर्टालआ दानि B2B आरो B2C नैथाय फिलिंगा खालामनो हुं।
  5. फाइलफोर डाउनलोड खालाम। Excel वर्कबुक (गासैबो टेबल) आव अफलाइन टुलनि सिट मुंफोर सोलोंगाव मोनसे फाइल लाबो; गासै CSV फाइलफोर आव टेबल मोनसे मोनसेनि थाखाय टुलनि निजि सिरिङ सोलोंगाव मोनसे मोनसे फाइल लाबो।
  6. JSON बानाय आरो फाइल खालाम। फाइलफोरखौ GST Returns Offline Tool आव इम्पर्ट खालाम, JSON बानाय, GST पोर्टालआव GSTR-1 आव आपलोड खालाम, बेयाव सारांस नाय आरो फाइल खालाम। नाय अफलाइन टुलआव माबोरै इम्पर्ट खालामनो।

बेयाव नोंथांनि थाखाय मा खालाम

  • गासै बिलखौ नोंथांनि थाखाय फिलिंगा खालाम: गाहायनि GSTIN, राज्य आरो बिलनि दामनि बाहागोनो, टेबल 4, 5, 6A, 7, 8, 9B, 11A, 12, 13 आव।
  • B2C Large नि ₹1 लाख सिमा अगस्ट 2024 समानिफ्राय उनाव बिलफोरनि थाखाय, आरो जुनार बिलनि थाखाय गोजोननि ₹2.5 लाख।
  • क्रेडिट आरो डेबिट नोटफोरखौ सावरायो: रेजिस्टार्ड गाहायफोरनि थाखाय 9B आव, आरो खुबु B2C बिलनि थाखाय रिटार्नआ मोनथाम बादि B2CS नि अंकाखौ खम एबा बांसिन खालायो।
  • HSN सारांस नैथाय फिलिंगा, B2B आरो B2C, रेट, बिबां आरो पोर्टालआ मोनथाम इउनिट कोड (UQC) सोलोंगाव; सार्भिस (SAC 99…) नि थाखाय बिबां गैया।
  • होनाय डकुमेन्ट (टेबल 13): नम्बार सिरिज मोनसे मोनसेनि सिगांनि नम्बार, जोबथानि नम्बार, जम्मा, आरो नम्बार बांखिनायनि एबा नैथाय जानायनि सावधान।
  • अफलाइन टुलनि रैखा: सिरिङफोर GST Returns Offline Tool V3.2.4 फाइलफोरनिफ्राय लानाय, तारिख DD-MMM-YYYY बादि, राज्य "07-Delhi" बादि।

नोंथांनि डेटा नोंथांनि थाव थायो

सारांसखौ बे ब्राउजारआव, नोंथांनि Nivesh Sahayak डेटा जायगा (my.niveshsahayak.in) आव सेभ जानाय बिलफोरनिफ्राय हिसाब खालामो। जोंनो एबा GST पोर्टालनो जेबो दैथिनाय जाया। रिटार्नखौ नोंथां गावनोगाव, नोंथांनि निजि लगिनजों, आपलोड खालामो।

फाइल खालामनाय सिगां नायमोन। बे नोंथांनि निजि बिलफोरनिफ्राय बानायनाय खामानि सिट। गुबुन सफ्टवेयारआव बानायनाय बिल, बातिल जानाय बिल, आरो सिगांनि आफादफोरनि सोलायनाय बेयाव गैया। नोंथांनि GSTR-1 आ नोंथांनि गावनोगाव जिम्मा; सन्देह दं जायोब्ला नोंथांनि अकाउन्टेन्टखौ सुं।

गाइड

GSTR-1 टेबल बुंनायमाव बिल माव टेबलआव थांनाय, फोरमायथिजों। GSTR-1 जोबथा तारिख आरो QRMPआफादिया, क्वार्टारिया, IFF, GSTR-1A आरो थाम बसरनि सिमा। HSN सारांस (टेबल 12)हांखो, B2B आरो B2C बाहागो, UQC आरो गोजोननि भुल। GST अफलाइन टुलआव इम्पर्टExcel एबा CSV निफ्राय फाइल जानाय GSTR-1 सिम।

मानसिफोरा माया सुं

बेयाव जों नोंथांनि GSTR-1 फाइल खालाइ ना?

नङा। बेयाव अंकाफोर आरो फाइलफोरखौ सैखालायो। नोंथां बेफोरखौ फ्री GST अफलाइन टुलआव इम्पर्ट खालायो, JSON खौ GST पोर्टालआव नोंथांनि निजि लगिनजों आपलोड खालायो आरो अननि फाइल खालायो।

बिलफोर माफ्रायनो थायो?

Nivesh Sahayak डकुमेन्ट साइटफोर (बिलिं, केस मेमो, क्रेडिट नोट, रसिद आरो गुबुन) जों बे ब्राउजारआव सेभ जानाय बिलफोरनिफ्राय। गुबुन सफ्टवेयारनिफ्राय बिलफोर बेयाव गैया।

JSON डाउनलोड मानो गैया?

GST पोर्टालनि JSON रैखा समाया समायाव सोलायो आरो सरकारि अफलाइन टुलनो गासैयाव मोजां मिलायो। बेनिखायनो जों अफलाइन टुलनि निजि रैखाव Excel आरो CSV होयो आरो JSON खौ टुलनो बानायो।

माव बिलफोर B2C Large आव थांनाय?

गुबुन राज्यनि रेजिस्टार्ड नङा गाहायफोरनि थाखाय ₹1 लाखनिफ्राय बांसिन बिलनि दाम दं बिलफोर (अगस्ट 2024 समानिफ्राय; सिगां ₹2.5 लाख)। गुबुन गासै B2C बिलफोर B2C Small आव फिलिंगा जायो।

क्वार्टारिया रिटार्नि थाखाय बाहायनो हायो ना?

हायो। "मोनसे क्वार्टार (QRMP)" आरो क्वार्टारनि जेबो आफाद बायनाय; आफाद सामसे गासै मोनसे थाव लानाय जायो।

बेयाव फ्री ना?

हो, गासै फ्री, लगिन गैया, बिलनि सिमा गैया।
