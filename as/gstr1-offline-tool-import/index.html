GST অফলাইন টুলত ইমপ’ৰ্ট কৰি GSTR-1 ফাইল কৰক

GST পোৰ্টেলে Excel পোনপটীয়াকৈ নলয়। তাৰ বিনামূলীয়া Returns Offline Tool-এ Excel বা CSV ফাইল পঢ়ি JSON ফাইল বনায়, আৰু আপলোড কৰিব লাগে সেই JSON। মেকাৰৰ ফাইলৰ পৰা ফাইল কৰা ৰিটাৰ্ণলৈকে গোটেই পথটো ইয়াত আছে।

এবাৰ: অফলাইন টুল লওক

  1. www.gst.gov.inত গৈ Downloads › Offline Tools › Returns Offline Tool খোলি নমাওক (এই পেজ লিখাৰ সময়ত, 4 নৱেম্বৰ 2026ত, ভাৰ্ছন আছিল 3.2.4)।
  2. জিপ খুলি GST Offline Tool ইনষ্টল কৰক। ই কেৱল Windows-ত চলে। জিপত চৰকাৰী Excel টেমপ্লেট আৰু নমুনা CSV ফাইলো থাকে।

প্ৰতি মাহে: JSON বনাওক

  1. GSTR-1 মেকাৰত ব্যৱসায় আৰু পিৰিয়ড বাচি Excel ৱাৰ্কবুক (সকলো টেবুল) টিপক। (বা প্ৰতিটো টেবুলৰ বাবে এটা ফাইলৰ বাবে সকলো CSV ফাইল।)
  2. অফলাইন টুল খোলক, New বাচক, GSTR-1 বাচক, আপোনাৰ GSTIN, ফিনান্সিয়েল ইয়েৰ আৰু টেক্স পিৰিয়ড লিখি Proceed টিপক।
  3. Import Files টিপক। ৱাৰ্কবুকৰ বাবে Import Excel; CSV হ’লে ছেকশ্বন (যেনে B2B) বাচি Import CSV ব্যৱহাৰ কৰক।
  4. View Summary টিপক আৰু মুঠ অংকবোৰ মেকাৰৰ টাইলৰ লগত মিলাই চাওক। টুলে দৰ আৰু টেক্সেবল ভেলুৰ পৰা টেক্স হিচাপ কৰে; আপোনাৰ বিলত বেলেগ অংক থাকিলে টেক্সৰ অংক সলনি কৰিব পাৰে।
  5. ফাইলে যিবোৰ বহন কৰিব নোৱাৰে সেইবোৰ যোগ কৰক: এক্সপৰ্টৰ বাবে প’ৰ্ট ক’ড আৰু শ্বিপিং বিল, আৰু জাৰি কৰা ডকুমেণ্ট আৰু নিল ৰেটেড টেবুল যদি টুলে ইমপ’ৰ্ট কৰা নাই (টুলৰ হেল্প শ্বীটে কয় এই দুটা হাতেৰে লিখিব লগা হ’ব পাৰে)।
  6. Generate File টিপক। টুলে আপোনাৰ কম্পিউটাৰত এটা JSON ফাইল ছেভ কৰে।

GST পোৰ্টেলত: আপলোড আৰু ফাইল

  1. লগইন কৰি Services › Returns › Returns Dashboardলৈ যাওক, বছৰ আৰু পিৰিয়ড বাচক।
  2. GSTR-1 টাইলত Prepare Offline বাচি Upload টিপক আৰু JSON ফাইলটো দিয়ক। ষ্টেটাছত প্ৰচেছ হ’ল বুলি নহালৈকে অপেক্ষা কৰক। ভুল দেখুৱালে এৰৰ ফাইল নমাওক, অফলাইন টুলত খোলি শুদ্ধ কৰি আকৌ আপলোড কৰক।
  3. উভতি আহি Prepare Online বাচি প্ৰতিটো টেবুল চাওক। IRP-ত আপুনি ৰেজিষ্টাৰ কৰা e-invoice ইয়াত নিজেই আহি যায়।
  4. Generate GSTR-1 Summary টিপক, চাই লওক, তাৰ পিছত DSC বা EVC (OTP)ৰে File Statement কৰক।

য’ত মানুহ আটকি যায়

  • e-invoice দুবাৰ আপলোড। e-invoicing কৰিলে সেই বিল IRP-ৰ পৰা আগতেই GSTR-1-ত আছে। একে ইনভইচ নম্বৰ আকৌ আপলোড কৰিলে এণ্ট্ৰি সলনি হয়; নিজে আকৌ যোগ নকৰি অটো-ভৰা এণ্ট্ৰিবোৰ চাই লওক।
  • তাৰিখ। টুলে বিচাৰে DD-MMM-YYYY (05-Nov-2026)। মেকাৰে এই ধৰণেই তাৰিখ লেখে; Excel-ত সলনি কৰিলে ঘৰবোৰ টেক্সট ৰাখক।
  • ৰাজ্য। প্লেচ অৱ ছাপ্লাই লিখিব লাগিব "03-Punjab" ধৰণে, টুলৰ তালিকাত যেনে আছে ঠিক তেনেকৈ।
  • পুৰণি টেমপ্লেট। অফলাইন টুলৰ ভৱিষ্যতৰ ভাৰ্ছনে নতুন টেমপ্লেট বিচাৰিলে আমাৰ ৱাৰ্কবুকৰ শাৰীবোৰ একে নামৰ শ্বীটত নতুন টেমপ্লেটলৈ কপি কৰক।
  • আন ছফ্টৱেৰৰ বিল। মেকাৰে কেৱল Nivesh Sahayak-ত ছেভ কৰা বিলহে চিনি পায়। JSON বনোৱাৰ আগতে আন বিলবোৰ অফলাইন টুলত যোগ কৰক।
