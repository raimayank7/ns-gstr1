আপোনাৰ বিলৰ পৰা বিনামূলীয়া GSTR-1 ছামাৰী

আপোনাৰ ব্যৱসায় আৰু মাহ বাচক। Nivesh Sahayak-ৰ ডকুমেণ্ট ছাইটবোৰত আপুনি ছেভ কৰা সকলো GST বিল আৰু ক্ৰেডিট নোট GSTR-1-ৰ টেবুলত সজোৱা হ’ব, লগত মুঠ অংক, সতৰ্কবাণী আৰু GST Returns Offline Tool-ৰ বাবে সাজু ফাইল। লগইনৰ প্ৰয়োজন নাই, একো আপলোড নহয়।

ইয়াত GSTR-1 ছামাৰী কেনেকৈ বনাব

  1. আগতে ইয়াতেই বিল বনাওক। billing.niveshsahayak.in-ত টেক্স ইনভইচ, GST সহ কেশ মেমো, আৰু credit-note.niveshsahayak.in-ত ক্ৰেডিট বা ডেবিট নোট এই ব্ৰাউজাৰত ছেভ হয়। এই পেজে সেইবোৰ পঢ়ি লয়; আপোনাক আকৌ একো টাইপ কৰিব নালাগে।
  2. ব্যৱসায় আৰু সময় বাচক। এটা মাহ বাচক, বা QRMP স্কিমত থাকিলে এটা কোৱাৰ্টাৰ। টাৰ্নঅভাৰৰ ঘৰটোও বাচক, যাতে HSN ক’ডত ঠিক কিমান সংখ্যা আছে সেয়া পৰীক্ষা হয়।
  3. সতৰ্কবাণীবোৰ পঢ়ক। HSN ক’ড নথকা, ক্ৰেতাৰ ভুল GSTIN, নম্বৰ ছিৰিজত ফাঁক, আৰু যিবোৰ নোটৰ মূল ইনভইচ ছেভ কৰা নাই, সেইবোৰ একেবাৰে ওপৰত দেখুওৱা হয়। বিলবোৰ সেইবোৰৰ নিজৰ ছাইটতে শুদ্ধ কৰক, তাৰ পিছত ছেভ কৰা বিল আকৌ পঢ়ক টিপক।
  4. প্ৰতিটো টেবুল চাওক। B2B বিল GSTIN সহ এটা এটাকৈ থাকে; সৰু B2C বিক্ৰী ৰাজ্য আৰু দৰ অনুসৰি যোগ কৰা হয়; HSN ছামাৰী এতিয়া পোৰ্টেলে যেনেকৈ বিচাৰে তেনেকৈ B2B আৰু B2C-ত ভাগ কৰা।
  5. ফাইল ডাউনলোড কৰক। Excel ৱাৰ্কবুক (সকলো টেবুল)-এ অফলাইন টুলৰ শ্বীটৰ নামসহ এটা ফাইল দিয়ে; সকলো CSV ফাইল-এ প্ৰতিটো টেবুলৰ বাবে টুলৰ নিজা হেডাৰ সহ এটা এটা ফাইল দিয়ে।
  6. JSON বনাই ফাইল কৰক। ফাইলবোৰ GST Returns Offline Tool-ত ইমপ’ৰ্ট কৰক, JSON বনাওক, GST পোৰ্টেলত GSTR-1-ত আপলোড কৰক, তাতে ছামাৰী চাই ফাইল কৰক। চাওক অফলাইন টুলত ইমপ’ৰ্ট কৰাৰ নিয়ম।

এইটোৱে আপোনাৰ বাবে কি কৰে

  • প্ৰতিটো বিল নিজে সজায়: ক্ৰেতাৰ GSTIN, ৰাজ্য আৰু বিলৰ মূল্য অনুসৰি টেবুল 4, 5, 6A, 7, 8, 9B, 11A, 12 আৰু 13-ত।
  • B2C Large-ৰ ₹1 লাখৰ সীমা ব্যৱহাৰ কৰে আগষ্ট 2024 পিৰিয়ডৰ পৰা, আৰু পুৰণি বিলৰ বাবে আগৰ ₹2.5 লাখ।
  • ক্ৰেডিট আৰু ডেবিট নোট সামৰে: ৰেজিষ্টাৰ্ড ক্ৰেতাৰ নোট 9B-লৈ যায়, আৰু সৰু B2C বিলৰ নোটে ৰিটাৰ্ণৰ নিয়ম অনুসৰি B2CS অংক কমায় বা বঢ়ায়।
  • HSN ছামাৰী দুই ভাগত, B2B আৰু B2C, পোৰ্টেলে মনা দৰ, পৰিমাণ আৰু ইউনিট ক’ড (UQC) সহ; ছাৰ্ভিচত (SAC 99…) পৰিমাণ নবহে।
  • জাৰি কৰা ডকুমেণ্ট (টেবুল 13): প্ৰতিটো নম্বৰ ছিৰিজৰ প্ৰথম আৰু শেষ নম্বৰ আৰু মুঠ সংখ্যা, নম্বৰ বাদ পৰিলে বা দুবাৰ থাকিলে সতৰ্কবাণী সহ।
  • অফলাইন টুলৰ লেআউট: GST Returns Offline Tool V3.2.4-ৰ ফাইলৰ পৰা হেডাৰ লোৱা, তাৰিখ DD-MMM-YYYY আৰু ৰাজ্য "07-Delhi" ধৰণে।

আপোনাৰ ডেটা আপোনাৰ ওচৰতে থাকে

ছামাৰী এই ব্ৰাউজাৰতে হিচাপ হয়, আপোনাৰ Nivesh Sahayak ডেটা হোমত (my.niveshsahayak.in) ছেভ কৰা বিলৰ পৰা। আমাৰ ওচৰলৈ বা GST পোৰ্টেললৈ একো পঠোৱা নহয়। ৰিটাৰ্ণ আপুনি নিজেই, নিজৰ লগইনেৰে আপলোড কৰিব।

ফাইল কৰাৰ আগতে পৰীক্ষা কৰক। এইটো আপোনাৰ নিজৰ বিলৰ পৰা বনোৱা এখন ৱাৰ্কিং শ্বীট। আন ছফ্টৱেৰত বনোৱা বিল, বাতিল বিল আৰু আগৰ মাহবোৰৰ সংশোধন ইয়াত নাই। আপোনাৰ GSTR-1-ৰ দায়িত্ব আপোনাৰ; সন্দেহ হ’লে একাউণ্টেণ্টক সুধিব।

গাইড

GSTR-1 টেবুল বুজি লওককোন বিল কোন টেবুলত যায়, উদাহৰণ সহ। GSTR-1 শেষ তাৰিখ আৰু QRMPমাহেকীয়া, ত্ৰৈমাসিক, IFF, GSTR-1A আৰু তিনি বছৰৰ সীমা। HSN ছামাৰী (টেবুল 12)কিমান সংখ্যা, B2B আৰু B2C ভাগ, UQC আৰু সাধাৰণ ভুল। GST অফলাইন টুলত ইমপ’ৰ্টExcel বা CSV-ৰ পৰা ফাইল কৰা GSTR-1 লৈকে।

মানুহে যি সোধে

এইটোৱে মোৰ GSTR-1 ফাইল কৰি দিয়েনে?

নিদিয়ে। এইটোৱে কেৱল হিচাপ আৰু ফাইল বনায়। আপুনি সেইবোৰ বিনামূলীয়া GST অফলাইন টুলত ইমপ’ৰ্ট কৰিব, নিজৰ লগইনেৰে GST পোৰ্টেলত JSON আপলোড কৰিব আৰু তাতেই ফাইল কৰিব।

বিলবোৰ ক’ৰ পৰা আহে?

Nivesh Sahayak-ৰ ডকুমেণ্ট ছাইটবোৰে (বিলিং, কেশ মেমো, ক্ৰেডিট নোট, ৰচিদ আদি) এই ব্ৰাউজাৰত যি ছেভ কৰিছে, তাৰ পৰা। আন ছফ্টৱেৰৰ বিল ইয়াত নাথাকে।

JSON ডাউনলোড কিয় নাই?

GST পোৰ্টেলৰ JSON ফৰ্মেট সময়ে সময়ে সলনি হয়, আৰু কেৱল চৰকাৰী অফলাইন টুলেহে নিশ্চিতভাৱে তাৰ লগত মিলে। গতিকে আমি অফলাইন টুলৰ নিজা লেআউটত Excel আৰু CSV দিওঁ, আৰু JSON টুলটোৱে নিজেই বনায়।

কোন বিল B2C Large-ত যায়?

আন ৰাজ্যৰ অৰেজিষ্টাৰ্ড ক্ৰেতাক দিয়া যিবোৰ বিলৰ মূল্য ₹1 লাখতকৈ বেছি (আগষ্ট 2024 পিৰিয়ডৰ পৰা; আগতে ₹2.5 লাখ আছিল)। বাকী সকলো B2C বিল B2C Small-ত যোগ হয়।

ত্ৰৈমাসিক ৰিটাৰ্ণৰ বাবে ব্যৱহাৰ কৰিব পাৰিনে?

পাৰি। “এটা কোৱাৰ্টাৰ (QRMP)” বাচক আৰু কোৱাৰ্টাৰৰ যিকোনো এটা মাহ দিয়ক; তিনিটা মাহ একেলগে ধৰা হ’ব।

ই বিনামূলীয়ানে?

হয়, সম্পূৰ্ণ বিনামূলীয়া। লগইনৰ প্ৰয়োজন নাই, বিলৰ সংখ্যাৰো সীমা নাই।
