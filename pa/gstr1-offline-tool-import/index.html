GSTR-1 › ਆਫ਼ਲਾਈਨ ਟੂਲ ਵਿੱਚ ਇੰਪੋਰਟ

GST ਆਫ਼ਲਾਈਨ ਟੂਲ ਵਿੱਚ ਇੰਪੋਰਟ ਕਰੋ ਅਤੇ GSTR-1 ਫ਼ਾਈਲ ਕਰੋ

GST ਪੋਰਟਲ Excel ਸਿੱਧਾ ਨਹੀਂ ਲੈਂਦਾ। ਉਸ ਦਾ ਮੁਫ਼ਤ Returns Offline Tool Excel ਜਾਂ CSV ਫ਼ਾਈਲਾਂ ਪੜ੍ਹ ਕੇ JSON ਫ਼ਾਈਲ ਬਣਾਉਂਦਾ ਹੈ, ਅਤੇ ਉਹੀ JSON ਤੁਸੀਂ ਅੱਪਲੋਡ ਕਰਦੇ ਹੋ। ਮੇਕਰ ਦੀਆਂ ਫ਼ਾਈਲਾਂ ਤੋਂ ਫ਼ਾਈਲ ਹੋਏ ਰਿਟਰਨ ਤੱਕ ਦਾ ਪੂਰਾ ਰਾਹ ਇੱਥੇ ਹੈ।

ਇੱਕ ਵਾਰ: ਆਫ਼ਲਾਈਨ ਟੂਲ ਲਓ

  1. www.gst.gov.in ’ਤੇ Downloads › Offline Tools › Returns Offline Tool ਵਿੱਚ ਜਾ ਕੇ ਉਸ ਨੂੰ ਡਾਊਨਲੋਡ ਕਰੋ (ਇਹ ਪੰਨਾ ਲਿਖਣ ਵੇਲੇ, 4 ਨਵੰਬਰ 2026 ਨੂੰ, ਵਰਜ਼ਨ 3.2.4 ਸੀ)।
  2. ਉਸ ਨੂੰ ਅਨਜ਼ਿੱਪ ਕਰੋ ਅਤੇ GST Offline Tool ਇੰਸਟਾਲ ਕਰੋ। ਇਹ ਸਿਰਫ਼ Windows ’ਤੇ ਚੱਲਦਾ ਹੈ। ਜ਼ਿੱਪ ਵਿੱਚ ਸਰਕਾਰੀ Excel ਟੈਂਪਲੇਟ ਅਤੇ ਸੈਂਪਲ CSV ਫ਼ਾਈਲਾਂ ਵੀ ਹੁੰਦੀਆਂ ਹਨ।

ਹਰ ਮਹੀਨੇ: JSON ਬਣਾਓ

  1. GSTR-1 ਮੇਕਰ ਵਿੱਚ ਬਿਜ਼ਨਸ ਅਤੇ ਮਿਆਦ ਚੁਣੋ ਅਤੇ Excel ਵਰਕਬੁੱਕ (ਸਾਰੇ ਟੇਬਲ) ਦਬਾਓ। (ਜਾਂ ਹਰ ਟੇਬਲ ਦੀ ਵੱਖਰੀ ਫ਼ਾਈਲ ਲਈ ਸਾਰੀਆਂ CSV ਫ਼ਾਈਲਾਂ।)
  2. ਆਫ਼ਲਾਈਨ ਟੂਲ ਖੋਲ੍ਹੋ, New ਚੁਣੋ, GSTR-1 ਚੁਣੋ, ਆਪਣਾ GSTIN, ਵਿੱਤੀ ਸਾਲ ਅਤੇ ਟੈਕਸ ਪੀਰੀਅਡ ਲਿਖੋ, ਅਤੇ Proceed ਦਬਾਓ।
  3. Import Files ਦਬਾਓ। ਵਰਕਬੁੱਕ ਲਈ Import Excel ਵਰਤੋ; CSV ਲਈ ਸੈਕਸ਼ਨ ਚੁਣੋ (ਜਿਵੇਂ B2B) ਅਤੇ Import CSV ਵਰਤੋ।
  4. View Summary ਦਬਾਓ ਅਤੇ ਟੋਟਲ ਨੂੰ ਮੇਕਰ ਦੀਆਂ ਟਾਈਲਾਂ ਨਾਲ ਮਿਲਾਓ। ਟੂਲ ਟੈਕਸ ਰੇਟ ਅਤੇ ਟੈਕਸੇਬਲ ਵੈਲਯੂ ਤੋਂ ਕੱਢਦਾ ਹੈ; ਤੁਹਾਡੇ ਬਿੱਲ ਵਿੱਚ ਕੋਈ ਹੋਰ ਟੈਕਸ ਰਕਮ ਹੈ ਤਾਂ ਤੁਸੀਂ ਉਸ ਨੂੰ ਬਦਲ ਸਕਦੇ ਹੋ।
  5. ਉਹ ਜੋੜੋ ਜੋ ਫ਼ਾਈਲਾਂ ਵਿੱਚ ਨਹੀਂ ਆ ਸਕਦਾ: ਐਕਸਪੋਰਟ ਲਈ ਪੋਰਟ ਕੋਡ ਅਤੇ ਸ਼ਿਪਿੰਗ ਬਿੱਲ, ਅਤੇ ਜਾਰੀ ਡਾਕੂਮੈਂਟ ਤੇ ਨਿਲ ਰੇਟਿਡ ਟੇਬਲ ਜੇ ਟੂਲ ਨੇ ਇੰਪੋਰਟ ਨਹੀਂ ਕੀਤੇ (ਉਸ ਦੀ ਹੈਲਪ ਸ਼ੀਟ ਕਹਿੰਦੀ ਹੈ ਕਿ ਇਹਨਾਂ ਦੋਵਾਂ ਨੂੰ ਹੱਥੀਂ ਭਰਨਾ ਪੈ ਸਕਦਾ ਹੈ)।
  6. Generate File ਦਬਾਓ। ਟੂਲ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ’ਤੇ ਇੱਕ JSON ਫ਼ਾਈਲ ਸੇਵ ਕਰਦਾ ਹੈ।

GST ਪੋਰਟਲ ’ਤੇ: ਅੱਪਲੋਡ ਕਰੋ ਅਤੇ ਫ਼ਾਈਲ ਕਰੋ

  1. ਲੌਗਇਨ ਕਰੋ, Services › Returns › Returns Dashboard ਵਿੱਚ ਜਾਓ, ਸਾਲ ਅਤੇ ਮਿਆਦ ਚੁਣੋ।
  2. GSTR-1 ਟਾਈਲ ਵਿੱਚ Prepare Offline ਚੁਣੋ, ਫਿਰ Upload, ਅਤੇ JSON ਫ਼ਾਈਲ ਚੁਣੋ। ਉਦੋਂ ਤੱਕ ਰੁਕੋ ਜਦੋਂ ਤੱਕ ਸਟੇਟਸ ਵਿੱਚ ਨਾ ਦਿਸੇ ਕਿ ਪ੍ਰੋਸੈੱਸ ਹੋ ਗਈ। ਐਰਰ ਦਿਸਣ ਤਾਂ ਐਰਰ ਫ਼ਾਈਲ ਡਾਊਨਲੋਡ ਕਰੋ, ਆਫ਼ਲਾਈਨ ਟੂਲ ਵਿੱਚ ਖੋਲ੍ਹੋ, ਠੀਕ ਕਰੋ ਅਤੇ ਫਿਰ ਅੱਪਲੋਡ ਕਰੋ।
  3. ਵਾਪਸ ਜਾਓ, Prepare Online ਚੁਣੋ ਅਤੇ ਹਰ ਟੇਬਲ ਜਾਂਚੋ। IRP ’ਤੇ ਰਜਿਸਟਰ ਕੀਤੇ ਈ-ਇਨਵੌਇਸ ਇੱਥੇ ਆਪਣੇ-ਆਪ ਦਿਖ ਜਾਂਦੇ ਹਨ।
  4. Generate GSTR-1 Summary ਦਬਾਓ, ਉਸ ਨੂੰ ਜਾਂਚੋ, ਫਿਰ DSC ਜਾਂ EVC (OTP) ਨਾਲ File Statement ਕਰੋ।

ਜਿੱਥੇ ਲੋਕ ਅਟਕਦੇ ਹਨ

  • ਈ-ਇਨਵੌਇਸ ਦੋ ਵਾਰ ਅੱਪਲੋਡ। ਜੇ ਤੁਸੀਂ ਈ-ਇਨਵੌਇਸਿੰਗ ਕਰਦੇ ਹੋ ਤਾਂ ਉਹ ਬਿੱਲ IRP ਤੋਂ ਪਹਿਲਾਂ ਹੀ GSTR-1 ਵਿੱਚ ਹੁੰਦੇ ਹਨ। ਉਹੀ ਇਨਵੌਇਸ ਨੰਬਰ ਦੁਬਾਰਾ ਅੱਪਲੋਡ ਕਰਨ ਨਾਲ ਐਂਟਰੀ ਬਦਲ ਜਾਂਦੀ ਹੈ; ਆਪਣੇ-ਆਪ ਭਰੀਆਂ ਐਂਟਰੀਆਂ ਜਾਂਚੋ, ਉਹਨਾਂ ਨੂੰ ਫਿਰ ਨਾ ਜੋੜੋ।
  • ਤਾਰੀਖ਼। ਟੂਲ ਨੂੰ DD-MMM-YYYY (05-Nov-2026) ਚਾਹੀਦੀ ਹੈ। ਮੇਕਰ ਤਾਰੀਖ਼ਾਂ ਇਸੇ ਤਰ੍ਹਾਂ ਲਿਖਦਾ ਹੈ; Excel ਵਿੱਚ ਬਦਲਾਅ ਕਰੋ ਤਾਂ ਸੈੱਲ ਟੈਕਸਟ ਹੀ ਰਹਿਣ ਦਿਓ।
  • ਰਾਜ। ਪਲੇਸ ਆਫ਼ ਸਪਲਾਈ "03-Punjab" ਵਾਂਗ ਹੀ ਲਿਖਿਆ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ, ਬਿਲਕੁਲ ਉਸੇ ਤਰ੍ਹਾਂ ਜਿਵੇਂ ਟੂਲ ਦੀ ਲਿਸਟ ਵਿੱਚ ਹੈ।
  • ਪੁਰਾਣਾ ਟੈਂਪਲੇਟ। ਆਫ਼ਲਾਈਨ ਟੂਲ ਦਾ ਅਗਲਾ ਵਰਜ਼ਨ ਨਵਾਂ ਟੈਂਪਲੇਟ ਮੰਗੇ ਤਾਂ ਸਾਡੀ ਵਰਕਬੁੱਕ ਦੀਆਂ ਕਤਾਰਾਂ ਨਵੇਂ ਟੈਂਪਲੇਟ ਦੀਆਂ ਉਹਨਾਂ ਨਾਵਾਂ ਵਾਲੀਆਂ ਸ਼ੀਟਾਂ ਵਿੱਚ ਕਾਪੀ ਕਰ ਦਿਓ।
  • ਹੋਰ ਸੌਫ਼ਟਵੇਅਰ ਦੇ ਬਿੱਲ। ਮੇਕਰ ਸਿਰਫ਼ Nivesh Sahayak ਵਿੱਚ ਸੇਵ ਬਿੱਲ ਜਾਣਦਾ ਹੈ। JSON ਬਣਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਹੋਰ ਬਿੱਲ ਆਫ਼ਲਾਈਨ ਟੂਲ ਵਿੱਚ ਜੋੜੋ।
ਇਸ ਮਹੀਨੇ ਦੇ ਬਿੱਲ ਹੁਣੇ GSTR-1 ਵਿੱਚ ਛਾਂਟੋ।ਮੇਕਰ ਖੋਲ੍ਹੋ
