GSTR-1 टेबलांनिमाणी तारीख

तुमच्या बिलांतल्यान फुकट GSTR-1 सारांश

तुमचो बिझनेस आनी म्हयनो वेंचात. Nivesh Sahayak डॉक्युमेंट साइटींवयल्यान सेव केल्लें दर GST बिल आनी क्रेडिट नोट GSTR-1 टेबलांनी लायतात, एकूण, वॉर्निंगो आनी GST Returns Offline Tool खातीर तयार फायलींसयत. लॉगिन ना, कांयच अपलोड जायना.

हांगा GSTR-1 सारांश कसो करचो

  1. पयलीं हांगा बिलां करात. billing.niveshsahayak.in वयल्यान केल्लीं टॅक्स इनवॉयस, GST आशिल्ले कॅश मेमो आनी credit-note.niveshsahayak.in वयल्यान केल्ल्यो क्रेडिट वा डेबिट नोटी ह्या ब्राउझरांत सेव जातात. हें पान तांकां वाचता; तुमी परत कांयच टाइप करचें पडना.
  2. बिझनेस आनी कालावधी वेंचात. एक म्हयनो वेंचात, वा तुमी QRMP योजनेंत आसल्यार एक तिमाही. तुमचो टर्नओव्हर गट वेंचात, म्हणजे HSN कोड बरोबर आंकड्यांखातीर तपासतात.
  3. वॉर्निंगो वाचात. HSN कोड नाशिल्ले, गिरायकाचो चुकीचो GSTIN, नंबर सिरीजींतले गॅप आनी जाच्या नोटीचो मूळ इनवॉयस सेव केल्लो ना अशा नोटी सगळ्यांत वयर दाखयतात. बिलां तांच्या तांच्या साइटीर सुदारात, मागीर सेव केल्लीं बिलां परतून वाचात दाबात.
  4. दर टेबल तपासात. B2B बिलां गिरायकाच्या GSTIN सयत एकेक करून येतात; ल्हान B2C विक्री राज्य आनी दरा प्रमाणें एकठांय करतात; HSN सारांश आतां पोर्टलाक जाय तसो B2B आनी B2C अशो दोन भागांनी आसता.
  5. फायली डाउनलोड करात. Excel वर्कबुक ऑफलाइन टूलाच्या शीट नांवांसयत एक फायल दिता; सगळ्यो CSV फायली दर टेबलाची वेगळी फायल टूलाच्या स्वताच्या हेडरांसयत दिता.
  6. JSON करात आनी फायल करात. फायली GST Returns Offline Tool आंत इम्पोर्ट करात, JSON तयार करात, GST पोर्टलार GSTR-1 आंत अपलोड करात, थंय सारांश तपासात आनी फायल करात. पळयात ऑफलाइन टूलांत इम्पोर्ट कशें करचें.

हें तुमचेखातीर कितें करता

  • दर बिल आपसूक लायता: गिरायकाचो GSTIN, राज्य आनी बिलाची रक्कम पळोवन टेबल 4, 5, 6A, 7, 8, 9B, 11A, 12 आनी 13 आंत.
  • B2C Large खातीर ₹1 लाखांची मर्यादा ऑगस्ट 2024 च्या कालावधीसावन फुडल्या बिलांखातीर, आनी जुन्या बिलांखातीर जुनी ₹2.5 लाखांची मर्यादा वापरता.
  • क्रेडिट आनी डेबिट नोटी सांबाळटा: रजिस्टर्ड गिरायकांच्यो नोटी 9B आंत, आनी ल्हान B2C बिलांखातीर रिटर्नाक जाय तशे B2CS चे आंकडे उणे वा चड करता.
  • HSN सारांश दोन भागांनी, B2B आनी B2C, दर, प्रमाण आनी पोर्टल मानून घेता ते युनिट कोड (UQC) सयत; सर्विसां (SAC 99…) खातीर प्रमाण आसना.
  • दिल्लीं डॉक्युमेंटां (टेबल 13): दर नंबर सिरीजीचो पयलो आनी निमाणो नंबर आनी एकूण, आनी नंबर सुटल्यार वा परत आयल्यार वॉर्निंग.
  • ऑफलाइन टूलाचो लेआउट: GST Returns Offline Tool V3.2.4 च्या फायलींतल्यान घेतिल्ले हेडर, तारखो DD-MMM-YYYY आनी राज्यां "07-Delhi" अशीं.

तुमचो डेटा तुमचेकडेच उरता

सारांश ह्याच ब्राउझरांत, तुमच्या Nivesh Sahayak डेटा होमांत (my.niveshsahayak.in) सेव केल्ल्या बिलांतल्यान काडटात. आमकां वा GST पोर्टलाक कांयच धाडिल्लें ना. रिटर्न तुमी स्वता, तुमच्याच लॉगिनान अपलोड करता.

फायल करचे पयलीं तपासात. ही तुमच्याच बिलांनी केल्ली वर्किंग शीट. हेर सॉफ्टवेअरांत केल्लीं बिलां, रद्द केल्लीं बिलां आनी फाटल्या म्हयन्यांचे अमेंडमेंट हांगा ना. तुमचें GSTR-1 ही तुमची जापसालदारकी; दुबाव आसल्यार तुमच्या अकाउंटंटाक विचारात.

गायड

GSTR-1 टेबलां समजून घेयातखंयचें बिल खंयच्या टेबलांत वता, उदाहरणां सयत. GSTR-1 ची निमाणी तारीख आनी QRMPम्हयनावारी, तिमाही, IFF, GSTR-1A आनी तीन वर्सांची मर्यादा. HSN सारांश (टेबल 12)आंकडे, B2B आनी B2C भाग, UQC आनी नेहमीच्यो चुकी. GST ऑफलाइन टूलांत इम्पोर्टExcel वा CSV सावन फायल जाल्ल्या GSTR-1 मेरेन.

लोक विचारतात ते प्रस्न

हें म्हजें GSTR-1 फायल करता?

ना. हें फक्त आंकडे आनी फायली तयार करता. तुमी तांकां फुकट GST ऑफलाइन टूलांत इम्पोर्ट करता, JSON फायल तुमच्याच लॉगिनान GST पोर्टलार अपलोड करता आनी थंयच फायल करता.

बिलां खंयसून येतात?

Nivesh Sahayak डॉक्युमेंट साइटींनी (बिलिंग, कॅश मेमो, क्रेडिट नोट, पावती आनी हेर) ह्या ब्राउझरांत सेव केल्ल्या बिलांतल्यान. हेर सॉफ्टवेअरांतलीं बिलां हांगा येनात.

JSON डाउनलोड कित्याक ना?

GST पोर्टलाचो JSON फॉर्मेट वेळांवेळार बदलता आनी फक्त अधिकृत ऑफलाइन टूलच ताचेकडेन खात्रीन जुळटा. देखून आमी ऑफलाइन टूलाच्या स्वताच्या लेआउटांत Excel आनी CSV दिता आनी JSON तें टूल तयार करता.

खंयचीं बिलां B2C Large आंत वचतात?

दुसऱ्या राज्यांतल्या रजिस्टर्ड नाशिल्ल्या गिरायकांक दिल्लीं, ₹1 लाखांपरस चड बिल रक्कम आशिल्लीं बिलां (ऑगस्ट 2024 च्या कालावधीसावन; ताचे पयलीं ₹2.5 लाख). उरिल्लीं सगळीं B2C बिलां B2C Small आंत एकठांय मेजतात.

तिमाही रिटर्नाखातीर वापरूं येता?

हय. “एक तिमाही (QRMP)” आनी तिमाहीतलो खंयचोय म्हयनो वेंचात; तिन्ही म्हयने एकठांय घेतात.

हें फुकट आसा?

हय, पुरायपणान फुकट. लॉगिन ना आनी बिलांची मर्यादा ना.
