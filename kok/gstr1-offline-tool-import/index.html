GSTR-1 › ऑफलाइन टूल इम्पोर्ट

GST ऑफलाइन टूलांत इम्पोर्ट करात आनी GSTR-1 फायल करात

GST पोर्टल Excel सरळ घेना. ताचें फुकट Returns Offline Tool Excel वा CSV फायली वाचून JSON फायल तयार करता, आनी तीच JSON तुमी अपलोड करता. मेकराच्या फायलींसावन फायल जाल्ल्या रिटर्नामेरेनचो सगळो मार्ग हांगा आसा.

एकदांच: ऑफलाइन टूल मेळयात

  1. www.gst.gov.in वयल्यान Downloads › Offline Tools › Returns Offline Tool आंत वचून तें डाउनलोड करात (हें पान बरयतना, 4 नोव्हेंबर 2026 दिसा, आवृत्ती 3.2.4).
  2. झिप उगडात आनी GST Offline Tool इन्स्टॉल करात. तें फक्त Windows वयल्यान चलता. झिपांत अधिकृत Excel टेम्पलेट आनी नमुनो CSV फायली लेगीत आसतात.

दर म्हयन्यांक: JSON करात

  1. GSTR-1 मेकरांत बिझनेस आनी कालावधी वेंचात आनी Excel वर्कबुक (सगळीं टेबलां) दाबात. (वा दर टेबलाची वेगळी फायल जाय जाल्यार सगळ्यो CSV फायली.)
  2. ऑफलाइन टूल उगडात, New वेंचात, GSTR-1 वेंचात, तुमचो GSTIN, आर्थिक वर्स आनी टॅक्स कालावधी बरयात आनी Proceed दाबात.
  3. Import Files दाबात. वर्कबुकाखातीर Import Excel वापरात; CSV खातीर विभाग (उदा. B2B) वेंचात आनी Import CSV वापरात.
  4. View Summary दाबात आनी एकूण आंकडे मेकराच्या टाइलांकडेन जुळोवन पळयात. टूल दर आनी टॅक्सेबल व्हॅल्यूवयल्यान टॅक्स काडटा; तुमच्या बिलाचेर वेगळी रक्कम आसल्यार टॅक्साची रक्कम तुमी बदलूं शकता.
  5. फायलींनी येवंक ना तें जोडात: एक्सपोर्टाखातीर पोर्ट कोड आनी शिपिंग बिल, आनी दिल्लीं डॉक्युमेंटां व निल रेटेड टेबलां टूलान इम्पोर्ट केल्यांत ना जाल्यार (ताच्या हेल्प शीटा प्रमाणें हीं दोन हातान बरोवचीं पडूं येतात).
  6. Generate File दाबात. टूल तुमच्या कॉम्प्युटरार JSON फायल सेव करता.

GST पोर्टलार: अपलोड करात आनी फायल करात

  1. लॉगिन करात, Services › Returns › Returns Dashboard आंत वचात, वर्स आनी कालावधी वेंचात.
  2. GSTR-1 टाइलांत Prepare Offline, मागीर Upload वेंचात आनी JSON फायल वेंचात. स्टेटस “processed” जायसर थांबात. एरर दिसल्यार एरर फायल डाउनलोड करात, ऑफलाइन टूलांत उगडात, सुदारात आनी परत अपलोड करात.
  3. फाटीं वचात, Prepare Online वेंचात आनी दर टेबल तपासात. IRP वयल्यान रजिस्टर केल्लीं ई-इनवॉयस हांगा आपसूक दिसतात.
  4. Generate GSTR-1 Summary दाबात, तपासात, मागीर DSC वा EVC (OTP) ने File Statement करात.

लोक खंय अडटात

  • ई-इनवॉयस दोन फावटी अपलोड. तुमी ई-इनवॉयसिंग वापरतात जाल्यार तीं बिलां IRP वयल्यान आदींच GSTR-1 आंत आयिल्लीं आसतात. तोच इनवॉयस नंबर परत अपलोड केल्यार एंट्री बदलता; आपसूक भरिल्ल्या एंट्री परत जोडचे परस तपासात.
  • तारखो. टूलाक DD-MMM-YYYY (05-Nov-2026) जाय. मेकर तारखो तशो बरयता; Excel आंत बदल करतना सेल टेक्स्ट म्हणूनच दवरात.
  • राज्यां. प्लेस ऑफ सप्लाय टूलाच्या यादी प्रमाणेंच "03-Punjab" अशें बरोवचें.
  • जुनें टेम्पलेट. ऑफलाइन टूलाची फुडली आवृत्ती नवें टेम्पलेट मागता जाल्यार आमच्या वर्कबुकांतल्यो वळी नव्या टेम्पलेटाच्या त्याच नांवाच्या शीटांत कॉपी करात.
  • हेर सॉफ्टवेअरांतलीं बिलां. मेकराक फक्त Nivesh Sahayak आंत सेव केल्लीं बिलां खबर आसतात. JSON करचे पयलीं हेर बिलां ऑफलाइन टूलांत जोडात.
