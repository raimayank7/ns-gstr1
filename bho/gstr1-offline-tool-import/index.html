GSTR-1 के टेबलआख़िरी तारीख

GSTR-1 › ऑफ़लाइन टूल में इम्पोर्ट

GST ऑफ़लाइन टूल में इम्पोर्ट करीं आ GSTR-1 फ़ाइल करीं

GST पोर्टल Excel सीधे नइखे लेत। ओकर फ्री Returns Offline Tool Excel भा CSV फ़ाइल पढ़ के JSON फ़ाइल बनावेला, आ उहे JSON रउआ अपलोड करीले। मेकर के फ़ाइल से फ़ाइल भइल रिटर्न तक के पूरा रस्ता इहाँ बा।

एक बेर: ऑफ़लाइन टूल लीं

  1. www.gst.gov.in पर Downloads › Offline Tools › Returns Offline Tool में जाके ओकरा के डाउनलोड करीं (ई पेज लिखत बेर, 4 नवंबर 2026 के, वर्शन 3.2.4 रहे)।
  2. ओकरा के अनज़िप करीं आ GST Offline Tool इंस्टॉल करीं। ई खाली Windows पर चलेला। ज़िप में सरकारी Excel टेम्पलेट आ सैंपल CSV फ़ाइल भी रहेला।

हर महीना: JSON बनाईं

  1. GSTR-1 मेकर में बिज़नेस आ अवधि चुनीं आ Excel वर्कबुक (सब टेबल) दबाईं। (भा हर टेबल के अलग फ़ाइल खातिर सब CSV फ़ाइल।)
  2. ऑफ़लाइन टूल खोलीं, New चुनीं, GSTR-1 चुनीं, आपन GSTIN, फ़ाइनेंशियल ईयर आ टैक्स पीरियड लिखीं, आ Proceed दबाईं।
  3. Import Files दबाईं। वर्कबुक खातिर Import Excel इस्तेमाल करीं; CSV खातिर सेक्शन चुनीं (जइसे B2B) आ Import CSV इस्तेमाल करीं।
  4. View Summary दबाईं आ टोटल के मेकर के टाइल से मिलाईं। टूल टैक्स रेट आ टैक्सेबल वैल्यू से निकालेला; रउआ बिल में कवनो दोसर टैक्स रकम बा त रउआ ओकरा के बदल सकिले।
  5. ऊ जोड़ीं जे फ़ाइल में ना आ सकेला: एक्सपोर्ट खातिर पोर्ट कोड आ शिपिंग बिल, आ जारी डॉक्यूमेंट व निल रेटेड टेबल अगर टूल इम्पोर्ट ना कइलस (ओकर हेल्प शीट कहेले कि इन दूनो के हाथ से भरे के पड़ सकेला)।
  6. Generate File दबाईं। टूल रउआ कंप्यूटर पर एगो JSON फ़ाइल सेव करेला।

GST पोर्टल पर: अपलोड करीं आ फ़ाइल करीं

  1. लॉगिन करीं, Services › Returns › Returns Dashboard में जाईं, साल आ अवधि चुनीं।
  2. GSTR-1 टाइल में Prepare Offline चुनीं, फेर Upload, आ JSON फ़ाइल चुनीं। तब तक रुकीं जब तक स्टेटस में ना देखाए कि प्रोसेस हो गइल। एरर देखाए त एरर फ़ाइल डाउनलोड करीं, ऑफ़लाइन टूल में खोलीं, ठीक करीं आ फेर अपलोड करीं।
  3. वापस जाईं, Prepare Online चुनीं आ हर टेबल जाँचीं। IRP पर रजिस्टर कइल ई-इनवॉइस इहाँ अपने-आप देखा जाला।
  4. Generate GSTR-1 Summary दबाईं, ओकरा के जाँचीं, फेर DSC भा EVC (OTP) से File Statement करीं।

जहाँ लोग अटकेला

  • ई-इनवॉइस दू बेर अपलोड। अगर रउआ ई-इनवॉइसिंग करीले त ऊ बिल IRP से पहिलहीं GSTR-1 में रहेला। ओही इनवॉइस नंबर के फेर अपलोड कइला से एंट्री बदल जाला; अपने-आप भरल एंट्री जाँचीं, ओकनी के फेर से मत जोड़ीं।
  • तारीख। टूल के DD-MMM-YYYY (05-Nov-2026) चाहीं। मेकर तारीख एही तरह लिखेला; Excel में बदलाव करीं त सेल टेक्स्ट ही रहे दीं।
  • राज्य। प्लेस ऑफ़ सप्लाई "03-Punjab" नियर ही लिखल होखे के चाहीं, ठीक ओइसहीं जइसे टूल के लिस्ट में बा।
  • पुरान टेम्पलेट। ऑफ़लाइन टूल के आगे के वर्शन नया टेम्पलेट माँगे त हमनी के वर्कबुक के पंक्ति नया टेम्पलेट के ओही नाम वाला शीट में कॉपी कर दीं।
  • दोसर सॉफ़्टवेयर के बिल। मेकर खाली Nivesh Sahayak में सेव बिल जानेला। JSON बनावे से पहिले दोसर बिल ऑफ़लाइन टूल में जोड़ीं।
एह महीना के बिल अबहीं GSTR-1 में छाँटीं।मेकर खोलीं
