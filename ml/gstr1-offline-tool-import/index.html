GSTR-1 › ഓഫ്‌ലൈൻ ടൂൾ ഇമ്പോർട്ട്

GST ഓഫ്‌ലൈൻ ടൂളിൽ ഇമ്പോർട്ട് ചെയ്ത് GSTR-1 ഫയൽ ചെയ്യുക

GST പോർട്ടൽ Excel നേരിട്ട് എടുക്കില്ല. അതിന്റെ സൗജന്യ Returns Offline Tool Excel അല്ലെങ്കിൽ CSV ഫയലുകൾ വായിച്ച് JSON ഫയൽ ഉണ്ടാക്കും, ആ JSON ആണ് നിങ്ങൾ അപ്‌ലോഡ് ചെയ്യുന്നത്. മേക്കറിന്റെ ഫയലുകൾ മുതൽ ഫയൽ ചെയ്ത റിട്ടേൺ വരെയുള്ള മുഴുവൻ വഴിയും ഇതാ.

ഒരിക്കൽ: ഓഫ്‌ലൈൻ ടൂൾ നേടുക

  1. www.gst.gov.in-ൽ Downloads › Offline Tools › Returns Offline Tool എന്നതിലേക്ക് പോയി ഡൗൺലോഡ് ചെയ്യുക (ഈ പേജ് എഴുതിയപ്പോൾ, 2026 നവംബർ 4-ന്, പതിപ്പ് 3.2.4).
  2. Zip അൺസിപ്പ് ചെയ്ത് GST Offline Tool ഇൻസ്റ്റാൾ ചെയ്യുക. ഇത് Windows-ൽ മാത്രമേ ഓടൂ. Zip-ൽ ഔദ്യോഗിക Excel ടെംപ്ലേറ്റും സാമ്പിൾ CSV ഫയലുകളും ഉണ്ട്.

ഓരോ മാസവും: JSON ഉണ്ടാക്കുക

  1. GSTR-1 മേക്കറിൽ ബിസിനസും കാലയളവും തിരഞ്ഞെടുത്ത് Excel വർക്ക്ബുക്ക് (എല്ലാ ടേബിളുകളും) അമർത്തുക. (അല്ലെങ്കിൽ ഓരോ ടേബിളിനും ഒരു ഫയലിനായി എല്ലാ CSV ഫയലുകളും.)
  2. ഓഫ്‌ലൈൻ ടൂൾ തുറന്ന് New തിരഞ്ഞെടുക്കുക, GSTR-1 തിരഞ്ഞെടുക്കുക, നിങ്ങളുടെ GSTIN, സാമ്പത്തിക വർഷം, നികുതി കാലയളവ് ടൈപ്പ് ചെയ്ത് Proceed അമർത്തുക.
  3. Import Files അമർത്തുക. വർക്ക്ബുക്കിന് Import Excel ഉപയോഗിക്കുക; CSV-ക്ക് വിഭാഗം (ഉദാഹരണത്തിന് B2B) തിരഞ്ഞെടുത്ത് Import CSV ഉപയോഗിക്കുക.
  4. View Summary അമർത്തി, ആകെത്തുകകൾ മേക്കറിന്റെ ടൈലുകളുമായി താരതമ്യം ചെയ്യുക. ടൂൾ നിരക്കിൽ നിന്നും നികുതി ബാധകമായ മൂല്യത്തിൽ നിന്നും നികുതി കണക്കാക്കും; നിങ്ങളുടെ ബില്ലിൽ വേറെ തുകയാണെങ്കിൽ നികുതി തുക തിരുത്താം.
  5. ഫയലുകൾക്ക് കൊണ്ടുപോകാൻ കഴിയാത്തത് ചേർക്കുക: കയറ്റുമതികൾക്ക് പോർട്ട് കോഡും ഷിപ്പിംഗ് ബില്ലും, ടൂൾ ഇമ്പോർട്ട് ചെയ്തില്ലെങ്കിൽ നൽകിയ ഡോക്യുമെന്റുകളും nil-rated ടേബിളുകളും (ഇവ രണ്ടും കൈകൊണ്ട് ടൈപ്പ് ചെയ്യേണ്ടി വന്നേക്കാമെന്ന് അതിന്റെ ഹെൽപ്പ് ഷീറ്റ് പറയുന്നു).
  6. Generate File അമർത്തുക. ടൂൾ നിങ്ങളുടെ കമ്പ്യൂട്ടറിൽ JSON ഫയൽ സേവ് ചെയ്യും.

GST പോർട്ടലിൽ: അപ്‌ലോഡ് ചെയ്ത് ഫയൽ ചെയ്യുക

  1. ലോഗിൻ ചെയ്ത്, Services › Returns › Returns Dashboard എന്നതിലേക്ക് പോയി, വർഷവും കാലയളവും തിരഞ്ഞെടുക്കുക.
  2. GSTR-1 ടൈലിൽ Prepare Offline, പിന്നെ Upload തിരഞ്ഞെടുത്ത് JSON ഫയൽ തിരഞ്ഞെടുക്കുക. സ്റ്റാറ്റസ് processed എന്ന് വരുന്നത് വരെ കാത്തിരിക്കുക. പിശകുകൾ കാണിച്ചാൽ എറർ ഫയൽ ഡൗൺലോഡ് ചെയ്ത്, ഓഫ്‌ലൈൻ ടൂളിൽ തുറന്ന്, തിരുത്തി, വീണ്ടും അപ്‌ലോഡ് ചെയ്യുക.
  3. തിരികെ വന്ന് Prepare Online തിരഞ്ഞെടുത്ത് ഓരോ ടേബിളും പരിശോധിക്കുക. IRP-യിൽ നിങ്ങൾ രജിസ്റ്റർ ചെയ്ത ഇ-ഇൻവോയ്സുകൾ ഇവിടെ ഇതിനകം തനിയെ കാണും.
  4. Generate GSTR-1 Summary അമർത്തി, പരിശോധിച്ച്, DSC അല്ലെങ്കിൽ EVC (OTP) ഉപയോഗിച്ച് File Statement ചെയ്യുക.

ആളുകൾ തെറ്റുന്ന ഇടങ്ങൾ

  • ഇ-ഇൻവോയ്സുകൾ രണ്ടുതവണ അപ്‌ലോഡ് ആകുന്നത്. ഇ-ഇൻവോയ്സിംഗ് ഉപയോഗിക്കുന്നെങ്കിൽ, ആ ബില്ലുകൾ IRP-യിൽ നിന്ന് ഇതിനകം GSTR-1-ൽ ഉണ്ട്. അതേ ഇൻവോയ്സ് നമ്പർ വീണ്ടും അപ്‌ലോഡ് ചെയ്താൽ എൻട്രി മാറ്റപ്പെടും; തനിയെ നിറഞ്ഞ എൻട്രികൾ വീണ്ടും ചേർക്കാതെ പരിശോധിക്കുക.
  • തീയതികൾ. ടൂളിന് DD-MMM-YYYY വേണം (05-Nov-2026). മേക്കർ തീയതികൾ ഇങ്ങനെയാണ് എഴുതുന്നത്; Excel-ൽ തിരുത്തിയാൽ സെല്ലുകൾ ടെക്സ്റ്റ് ആയി തന്നെ വെക്കുക.
  • സംസ്ഥാനങ്ങൾ. വിതരണ സ്ഥലം ടൂളിന്റെ പട്ടികയിലുള്ളതുപോലെ തന്നെ "03-Punjab" എന്ന് എഴുതണം.
  • പഴയ ടെംപ്ലേറ്റ്. ഓഫ്‌ലൈൻ ടൂളിന്റെ ഭാവി പതിപ്പ് പുതിയ ടെംപ്ലേറ്റ് ചോദിച്ചാൽ, ഞങ്ങളുടെ വർക്ക്ബുക്കിലെ വരികൾ പുതിയ ടെംപ്ലേറ്റിലെ അതേ പേരുള്ള ഷീറ്റുകളിലേക്ക് കോപ്പി ചെയ്യുക.
  • മറ്റ് സോഫ്റ്റ്‌വെയറിലെ ബില്ലുകൾ. മേക്കറിന് Nivesh Sahayak-ൽ സേവ് ചെയ്ത ബില്ലുകൾ മാത്രമേ അറിയൂ. JSON ഉണ്ടാക്കുന്നതിന് മുൻപ് മറ്റ് ബില്ലുകൾ ഓഫ്‌ലൈൻ ടൂളിൽ ചേർക്കുക.
ഈ മാസത്തെ ബില്ലുകൾ ഇപ്പോൾ തന്നെ GSTR-1-ലേക്ക് തിരിക്കുക.മേക്കർ തുറക്കുക
