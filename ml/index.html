നിങ്ങളുടെ ബിസിനസും മാസവും തിരഞ്ഞെടുക്കുക. Nivesh Sahayak ഡോക്യുമെന്റ് സൈറ്റുകളിൽ നിങ്ങൾ സേവ് ചെയ്ത ഓരോ GST ബില്ലും ക്രെഡിറ്റ് നോട്ടും GSTR-1 ടേബിളുകളായി തിരിക്കും; ആകെത്തുകകൾ, മുന്നറിയിപ്പുകൾ, GST Returns Offline Tool-ന് തയ്യാറായ ഫയലുകൾ എന്നിവ കിട്ടും. ലോഗിൻ വേണ്ട, ഒന്നും അപ്‌ലോഡ് ആകില്ല.

ഇവിടെ GSTR-1 സംഗ്രഹം എങ്ങനെ ഉണ്ടാക്കാം

  1. ആദ്യം ഇവിടെ ബില്ലുകൾ ഉണ്ടാക്കുക. billing.niveshsahayak.in-ൽ ടാക്സ് ഇൻവോയ്സുകൾ, GST സഹിതമുള്ള ക്യാഷ് മെമ്മോകൾ, credit-note.niveshsahayak.in-ൽ ക്രെഡിറ്റ് അല്ലെങ്കിൽ ഡെബിറ്റ് നോട്ടുകൾ ഈ ബ്രൗസറിൽ സേവ് ആകും. ഈ പേജ് അവ വായിക്കും; ഒന്നും വീണ്ടും ടൈപ്പ് ചെയ്യേണ്ടതില്ല.
  2. ബിസിനസും കാലയളവും തിരഞ്ഞെടുക്കുക. ഒരു മാസം, അല്ലെങ്കിൽ QRMP സ്കീമിലാണെങ്കിൽ ഒരു പാദം. HSN കോഡുകൾ ശരിയായ അക്കങ്ങൾക്ക് പരിശോധിക്കാൻ നിങ്ങളുടെ ടേൺഓവർ ബാൻഡ് തിരഞ്ഞെടുക്കുക.
  3. മുന്നറിയിപ്പുകൾ വായിക്കുക. HSN കോഡ് ഇല്ലാത്തവ, തെറ്റായ വാങ്ങുന്നയാളുടെ GSTIN, നമ്പർ സീരീസിലെ വിടവുകൾ, യഥാർത്ഥ ഇൻവോയ്സ് സേവ് ചെയ്യാത്ത നോട്ടുകൾ എന്നിവ മുകളിൽ പട്ടികയായി കാണും. ബില്ലുകൾ അവയുടെ സ്വന്തം സൈറ്റിൽ തിരുത്തി, പിന്നെ സേവ് ചെയ്ത ബില്ലുകൾ വീണ്ടും വായിക്കുക അമർത്തുക.
  4. ഓരോ ടേബിളും പരിശോധിക്കുക. B2B ബില്ലുകൾ വാങ്ങുന്നയാളുടെ GSTIN സഹിതം ഓരോന്നായി കാണിക്കും; ചെറിയ B2C വിൽപ്പനകൾ സംസ്ഥാനവും നിരക്കും അനുസരിച്ച് കൂട്ടും; പോർട്ടൽ ഇപ്പോൾ ചോദിക്കുന്നതുപോലെ HSN സംഗ്രഹം B2B, B2C എന്ന് രണ്ടായി തിരിക്കും.
  5. ഫയലുകൾ ഡൗൺലോഡ് ചെയ്യുക. Excel വർക്ക്ബുക്ക് (എല്ലാ ടേബിളുകളും) ഓഫ്‌ലൈൻ ടൂളിന്റെ ഷീറ്റ് പേരുകളോടെ ഒറ്റ ഫയൽ തരും; എല്ലാ CSV ഫയലുകളും ടൂളിന്റെ സ്വന്തം ഹെഡറുകളോടെ ഓരോ ടേബിളിനും ഓരോ ഫയൽ തരും.
  6. JSON ഉണ്ടാക്കി ഫയൽ ചെയ്യുക. ഫയലുകൾ GST Returns Offline Tool-ൽ ഇമ്പോർട്ട് ചെയ്ത് JSON ഉണ്ടാക്കി, GST പോർട്ടലിൽ GSTR-1-ൽ അപ്‌ലോഡ് ചെയ്ത്, അവിടെ സംഗ്രഹം നോക്കി ഫയൽ ചെയ്യുക. ഓഫ്‌ലൈൻ ടൂളിൽ ഇമ്പോർട്ട് ചെയ്യുന്ന വിധം കാണുക.

ഇത് നിങ്ങൾക്കായി എന്തു ചെയ്യുന്നു

  • ഓരോ ബില്ലും നിങ്ങൾക്കായി തിരിക്കുന്നു: വാങ്ങുന്നയാളുടെ GSTIN, സംസ്ഥാനം, ബിൽ മൂല്യം എന്നിവ അനുസരിച്ച് ടേബിളുകൾ 4, 5, 6A, 7, 8, 9B, 11A, 12, 13-ലേക്ക്.
  • B2C Large പരിധി ₹1 ലക്ഷം 2024 ഓഗസ്റ്റ് കാലയളവ് മുതലുള്ള ബില്ലുകൾക്ക്; പഴയ ബില്ലുകൾക്ക് പഴയ ₹2.5 ലക്ഷം.
  • ക്രെഡിറ്റ്, ഡെബിറ്റ് നോട്ടുകൾ: രജിസ്റ്റർ ചെയ്ത വാങ്ങുന്നവർക്കുള്ളവ 9B-യിൽ; ചെറിയ B2C ബില്ലുകൾക്ക് റിട്ടേൺ പ്രതീക്ഷിക്കുന്നതുപോലെ B2CS കണക്കുകൾ കുറയ്ക്കുകയോ കൂട്ടുകയോ ചെയ്യും.
  • HSN സംഗ്രഹം രണ്ട് ഭാഗങ്ങളായി, B2B, B2C, നിരക്ക്, അളവ്, പോർട്ടൽ സ്വീകരിക്കുന്ന യൂണിറ്റ് കോഡുകൾ (UQC) എന്നിവ സഹിതം; സർവീസുകൾക്ക് (SAC 99…) അളവ് ഇല്ല.
  • നൽകിയ ഡോക്യുമെന്റുകൾ (ടേബിൾ 13): ഓരോ നമ്പർ സീരീസിനും ആദ്യ, അവസാന നമ്പറും ആകെയും; നമ്പറുകൾ വിട്ടുപോയാലോ ആവർത്തിച്ചാലോ മുന്നറിയിപ്പ്.
  • ഓഫ്‌ലൈൻ ടൂൾ ലേഔട്ട്: GST Returns Offline Tool V3.2.4 ഫയലുകളുടെ ഹെഡറുകൾ അതുപോലെ, തീയതികൾ DD-MMM-YYYY, സംസ്ഥാനങ്ങൾ "07-Delhi" പോലെ.

നിങ്ങളുടെ ഡാറ്റ നിങ്ങളുടെ കൈയിൽ തന്നെ

നിങ്ങളുടെ Nivesh Sahayak ഡാറ്റ ഹോമിൽ (my.niveshsahayak.in) സേവ് ചെയ്ത ബില്ലുകളിൽ നിന്ന് ഈ സംഗ്രഹം ഈ ബ്രൗസറിൽ തന്നെ കണക്കാക്കുന്നു. ഒന്നും ഞങ്ങൾക്കോ GST പോർട്ടലിലേക്കോ അയയ്ക്കില്ല. റിട്ടേൺ നിങ്ങൾ തന്നെ, നിങ്ങളുടെ സ്വന്തം ലോഗിൻ ഉപയോഗിച്ച് അപ്‌ലോഡ് ചെയ്യുന്നു.

ഫയൽ ചെയ്യുന്നതിന് മുൻപ് പരിശോധിക്കുക. ഇത് നിങ്ങളുടെ സ്വന്തം ബില്ലുകളിൽ നിന്ന് ഉണ്ടാക്കിയ ഒരു വർക്കിംഗ് ഷീറ്റ് ആണ്. മറ്റ് സോഫ്റ്റ്‌വെയറിൽ ഉണ്ടാക്കിയ ബില്ലുകൾ, റദ്ദാക്കിയ ബില്ലുകൾ, മുൻ മാസങ്ങളിലെ തിരുത്തലുകൾ എന്നിവ ഇതിലില്ല. നിങ്ങളുടെ GSTR-1 നിങ്ങളുടെ ഉത്തരവാദിത്തമാണ്; സംശയമുണ്ടെങ്കിൽ നിങ്ങളുടെ അക്കൗണ്ടന്റിനോട് ചോദിക്കുക.

ഗൈഡുകൾ

GSTR-1 ടേബിളുകൾ വിശദീകരണംഏത് ബിൽ ഏത് ടേബിളിൽ, ഉദാഹരണങ്ങൾ സഹിതം. GSTR-1 അവസാന തീയതിയും QRMP-യുംപ്രതിമാസം, ത്രൈമാസം, IFF, GSTR-1A, മൂന്ന് വർഷത്തെ പരിധി. HSN സംഗ്രഹം (ടേബിൾ 12)അക്കങ്ങൾ, B2B, B2C ഭാഗങ്ങൾ, UQC, സാധാരണ തെറ്റുകൾ. GST ഓഫ്‌ലൈൻ ടൂളിൽ ഇമ്പോർട്ട്Excel അല്ലെങ്കിൽ CSV മുതൽ ഫയൽ ചെയ്ത GSTR-1 വരെ.

ആളുകൾ ചോദിക്കുന്ന ചോദ്യങ്ങൾ

ഇത് എന്റെ GSTR-1 ഫയൽ ചെയ്യുമോ?

ഇല്ല. ഇത് കണക്കുകളും ഫയലുകളും മാത്രം തയ്യാറാക്കും. അവ സൗജന്യ GST ഓഫ്‌ലൈൻ ടൂളിൽ ഇമ്പോർട്ട് ചെയ്ത്, JSON നിങ്ങളുടെ സ്വന്തം ലോഗിൻ ഉപയോഗിച്ച് GST പോർട്ടലിൽ അപ്‌ലോഡ് ചെയ്ത്, അവിടെത്തന്നെ ഫയൽ ചെയ്യുക.

ബില്ലുകൾ എവിടെ നിന്നാണ് വരുന്നത്?

Nivesh Sahayak ഡോക്യുമെന്റ് സൈറ്റുകൾ (ബില്ലിംഗ്, ക്യാഷ് മെമ്മോ, ക്രെഡിറ്റ് നോട്ട്, രസീത് തുടങ്ങിയവ) ഈ ബ്രൗസറിൽ സേവ് ചെയ്ത ബില്ലുകളിൽ നിന്ന്. മറ്റ് സോഫ്റ്റ്‌വെയറിൽ ഉണ്ടാക്കിയ ബില്ലുകൾ ഉൾപ്പെടില്ല.

JSON ഡൗൺലോഡ് എന്തുകൊണ്ട് ഇല്ല?

GST പോർട്ടലിന്റെ JSON ഫോർമാറ്റ് ഇടയ്ക്കിടെ മാറും, അതിനോട് കൃത്യമായി യോജിക്കുന്നത് ഔദ്യോഗിക ഓഫ്‌ലൈൻ ടൂൾ മാത്രമാണ്. അതുകൊണ്ട് ഓഫ്‌ലൈൻ ടൂളിന്റെ സ്വന്തം ലേഔട്ടിൽ Excel, CSV തരുന്നു, JSON ആ ടൂൾ ഉണ്ടാക്കും.

ഏത് ബില്ലുകളാണ് B2C Large-ലേക്ക് പോകുന്നത്?

മറ്റൊരു സംസ്ഥാനത്തുള്ള, രജിസ്ട്രേഷൻ ഇല്ലാത്ത വാങ്ങുന്നവർക്കുള്ള, ബിൽ മൂല്യം ₹1 ലക്ഷത്തിന് മുകളിലുള്ള ബില്ലുകൾ (2024 ഓഗസ്റ്റ് കാലയളവ് മുതൽ; അതിന് മുൻപ് ₹2.5 ലക്ഷം). മറ്റ് എല്ലാ B2C ബില്ലുകളും B2C Small-ൽ കൂട്ടിച്ചേർക്കും.

ത്രൈമാസ റിട്ടേണിന് ഉപയോഗിക്കാമോ?

ഉപയോഗിക്കാം. "ഒരു പാദം (QRMP)" എന്നതും ആ പാദത്തിലെ ഏതെങ്കിലും ഒരു മാസവും തിരഞ്ഞെടുക്കുക; മൂന്ന് മാസവും ഒരുമിച്ച് എടുക്കും.

ഇത് സൗജന്യമാണോ?

അതെ, പൂർണ്ണമായും സൗജന്യം. ലോഗിൻ വേണ്ട, ബില്ലുകൾക്ക് പരിധിയും ഇല്ല.
