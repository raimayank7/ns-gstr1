GSTR-1 › ઑફલાઇન ટૂલ ઇમ્પોર્ટ

GST ઑફલાઇન ટૂલમાં ઇમ્પોર્ટ કરો અને GSTR-1 ફાઇલ કરો

GST પોર્ટલ Excel સીધું લેતું નથી. તેનું મફત Returns Offline Tool Excel કે CSV ફાઇલો વાંચીને JSON ફાઇલ બનાવે છે, અને એ JSON તમે અપલોડ કરો છો. મેકરની ફાઇલોથી ફાઇલ થયેલા રિટર્ન સુધીનો આખો રસ્તો અહીં છે.

એક વાર: ઑફલાઇન ટૂલ મેળવો

  1. www.gst.gov.in પર Downloads › Offline Tools › Returns Offline Tool માં જઈને ડાઉનલોડ કરો (આ પેજ લખતી વખતે, 4 નવેમ્બર 2026 ના રોજ, આવૃત્તિ 3.2.4).
  2. ઝિપ ખોલો અને GST Offline Tool ઇન્સ્ટૉલ કરો. તે ફક્ત Windows પર ચાલે છે. ઝિપમાં સત્તાવાર Excel ટેમ્પ્લેટ અને નમૂનાની CSV ફાઇલો પણ હોય છે.

દર મહિને: JSON બનાવો

  1. GSTR-1 મેકરમાં બિઝનેસ અને સમયગાળો પસંદ કરો અને Excel વર્કબુક (બધાં ટેબલ) દબાવો. (અથવા દરેક ટેબલની અલગ ફાઇલ જોઈએ તો બધી CSV ફાઇલો.)
  2. ઑફલાઇન ટૂલ ખોલો, New પસંદ કરો, GSTR-1 પસંદ કરો, તમારો GSTIN, નાણાકીય વર્ષ અને ટેક્સ સમયગાળો લખો અને Proceed દબાવો.
  3. Import Files દબાવો. વર્કબુક માટે Import Excel વાપરો; CSV માટે વિભાગ (દા.ત. B2B) પસંદ કરો અને Import CSV વાપરો.
  4. View Summary દબાવો અને કુલ આંકડા મેકરની ટાઇલ સાથે મેળવો. ટૂલ દર અને ટેક્સેબલ વેલ્યુ પરથી ટેક્સ કાઢે છે; તમારા બિલ પર અલગ રકમ હોય તો ટેક્સની રકમ તમે બદલી શકો છો.
  5. ફાઇલો જે લાવી શકતી નથી તે ઉમેરો: એક્સપોર્ટ માટે પોર્ટ કોડ અને શિપિંગ બિલ, અને આપેલાં ડોક્યુમેન્ટ તથા નિલ રેટેડ ટેબલ જો ટૂલે ઇમ્પોર્ટ ન કર્યાં હોય (તેની હેલ્પ શીટ મુજબ આ બે હાથે લખવાં પડી શકે).
  6. Generate File દબાવો. ટૂલ તમારા કમ્પ્યુટર પર JSON ફાઇલ સેવ કરે છે.

GST પોર્ટલ પર: અપલોડ કરો અને ફાઇલ કરો

  1. લૉગિન કરો, Services › Returns › Returns Dashboard માં જાઓ, વર્ષ અને સમયગાળો પસંદ કરો.
  2. GSTR-1 ટાઇલમાં Prepare Offline, પછી Upload પસંદ કરો અને JSON ફાઇલ પસંદ કરો. સ્ટેટસ “processed” થાય ત્યાં સુધી રાહ જુઓ. એરર દેખાય તો એરર ફાઇલ ડાઉનલોડ કરો, ઑફલાઇન ટૂલમાં ખોલો, સુધારો અને ફરી અપલોડ કરો.
  3. પાછા જાઓ, Prepare Online પસંદ કરો અને દરેક ટેબલ તપાસો. IRP પર રજિસ્ટર કરેલાં ઈ-ઇન્વૉઇસ અહીં આપોઆપ દેખાય છે.
  4. Generate GSTR-1 Summary દબાવો, તપાસો, પછી DSC કે EVC (OTP) થી File Statement કરો.

લોકો ક્યાં અટકે છે

  • ઈ-ઇન્વૉઇસ બે વાર અપલોડ. તમે ઈ-ઇન્વૉઇસિંગ વાપરતા હો તો તે બિલ IRP પરથી પહેલેથી GSTR-1 માં આવી ગયાં હોય છે. એ જ ઇન્વૉઇસ નંબર ફરી અપલોડ કરો તો એન્ટ્રી બદલાઈ જાય છે; આપોઆપ ભરાયેલી એન્ટ્રી ફરી ઉમેરવાને બદલે તપાસો.
  • તારીખો. ટૂલને DD-MMM-YYYY (05-Nov-2026) જોઈએ. મેકર તારીખ એ રીતે લખે છે; Excel માં ફેરફાર કરો તો સેલ ટેક્સ્ટ તરીકે જ રાખો.
  • રાજ્યો. પ્લેસ ઑફ સપ્લાય ટૂલની યાદી પ્રમાણે જ "03-Punjab" એમ લખવું.
  • જૂનું ટેમ્પ્લેટ. ઑફલાઇન ટૂલની આગળની આવૃત્તિ નવું ટેમ્પ્લેટ માગે તો અમારી વર્કબુકની લીટીઓ નવા ટેમ્પ્લેટની એ જ નામની શીટમાં કૉપી કરો.
  • બીજા સૉફ્ટવેરનાં બિલ. મેકર ફક્ત Nivesh Sahayak માં સેવ કરેલાં બિલ જ જાણે છે. JSON બનાવતા પહેલાં બીજાં બિલ ઑફલાઇન ટૂલમાં ઉમેરો.
આ મહિનાનાં બિલ હમણાં જ GSTR-1 માં ગોઠવો.મેકર ખોલો
