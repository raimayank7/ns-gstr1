તમારાં બિલમાંથી મફત GSTR-1 સારાંશ

તમારો બિઝનેસ અને મહિનો પસંદ કરો. Nivesh Sahayak ડોક્યુમેન્ટ સાઇટ્સ પર સેવ કરેલું દરેક GST બિલ અને ક્રેડિટ નોટ GSTR-1 ટેબલમાં ગોઠવાય છે, કુલ, ચેતવણીઓ અને GST Returns Offline Tool માટે તૈયાર ફાઇલો સાથે. લૉગિન નથી, કંઈ અપલોડ થતું નથી.

અહીં GSTR-1 સારાંશ કેવી રીતે બનાવવો

  1. પહેલાં અહીં બિલ બનાવો. billing.niveshsahayak.in પર બનાવેલાં ટેક્સ ઇન્વૉઇસ, GST વાળા કૅશ મેમો અને credit-note.niveshsahayak.in પર બનાવેલી ક્રેડિટ કે ડેબિટ નોટ આ બ્રાઉઝરમાં સેવ થાય છે. આ પેજ તેમને વાંચે છે; તમારે ફરી કંઈ ટાઇપ કરવું પડતું નથી.
  2. બિઝનેસ અને સમયગાળો પસંદ કરો. એક મહિનો પસંદ કરો, અથવા તમે QRMP યોજનામાં હો તો એક ક્વાર્ટર. તમારું ટર્નઓવર જૂથ પસંદ કરો, જેથી HSN કોડ સાચા અંકો માટે તપાસાય.
  3. ચેતવણીઓ વાંચો. HSN કોડ ન હોવો, ખરીદનારનો ખોટો GSTIN, નંબર સિરીઝમાં ગાબડાં અને જેનું મૂળ ઇન્વૉઇસ સેવ નથી તેવી નોટ સૌથી ઉપર બતાવાય છે. બિલ તેમની પોતાની સાઇટ પર સુધારો, પછી સેવ કરેલાં બિલ ફરી વાંચો દબાવો.
  4. દરેક ટેબલ તપાસો. B2B બિલ ખરીદનારના GSTIN સાથે એક-એક કરીને આવે છે; નાની B2C વેચાણ રાજ્ય અને દર પ્રમાણે ભેગું કરાય છે; HSN સારાંશ હવે પોર્ટલ માગે છે તેમ B2B અને B2C એમ બે ભાગમાં હોય છે.
  5. ફાઇલો ડાઉનલોડ કરો. Excel વર્કબુક ઑફલાઇન ટૂલનાં શીટ નામો સાથે એક ફાઇલ આપે છે; બધી CSV ફાઇલો દરેક ટેબલની અલગ ફાઇલ ટૂલનાં પોતાનાં હેડર સાથે આપે છે.
  6. JSON બનાવો અને ફાઇલ કરો. ફાઇલો GST Returns Offline Tool માં ઇમ્પોર્ટ કરો, JSON બનાવો, GST પોર્ટલ પર GSTR-1 માં અપલોડ કરો, ત્યાં સારાંશ તપાસો અને ફાઇલ કરો. જુઓ ઑફલાઇન ટૂલમાં ઇમ્પોર્ટ કેવી રીતે કરવું.

તે તમારા માટે શું કરે છે

  • દરેક બિલ આપોઆપ ગોઠવે છે: ખરીદનારના GSTIN, રાજ્ય અને બિલની રકમ જોઈને ટેબલ 4, 5, 6A, 7, 8, 9B, 11A, 12 અને 13 માં.
  • B2C Large માટે ₹1 લાખની મર્યાદા ઑગસ્ટ 2024 ના સમયગાળાથી આગળનાં બિલ માટે, અને જૂનાં બિલ માટે જૂની ₹2.5 લાખની મર્યાદા વાપરે છે.
  • ક્રેડિટ અને ડેબિટ નોટ સંભાળે છે: રજિસ્ટર્ડ ખરીદનારની નોટ 9B માં, અને નાનાં B2C બિલ માટે રિટર્નને જોઈએ તેમ B2CS ના આંકડા ઘટાડે કે વધારે છે.
  • HSN સારાંશ બે ભાગમાં, B2B અને B2C, દર, જથ્થો અને પોર્ટલ સ્વીકારે તેવા યુનિટ કોડ (UQC) સાથે; સર્વિસ (SAC 99…) માટે જથ્થો હોતો નથી.
  • આપેલાં ડોક્યુમેન્ટ (ટેબલ 13): દરેક નંબર સિરીઝનો પહેલો અને છેલ્લો નંબર અને કુલ, અને નંબર છૂટી જાય કે ફરી આવે તો ચેતવણી.
  • ઑફલાઇન ટૂલનું લેઆઉટ: GST Returns Offline Tool V3.2.4 ની ફાઇલોમાંથી લીધેલાં હેડર, તારીખ DD-MMM-YYYY માં અને રાજ્યો "07-Delhi" જેમ.

તમારો ડેટા તમારી પાસે જ રહે છે

સારાંશ આ બ્રાઉઝરમાં જ, તમારા Nivesh Sahayak ડેટા હોમ (my.niveshsahayak.in) માં સેવ કરેલાં બિલ પરથી બને છે. અમને કે GST પોર્ટલને કંઈ મોકલાતું નથી. રિટર્ન તમે પોતે, પોતાના લૉગિનથી અપલોડ કરો છો.

ફાઇલ કરતાં પહેલાં તપાસો. આ તમારાં જ બિલમાંથી બનેલી વર્કિંગ શીટ છે. બીજા સૉફ્ટવેરમાં બનેલાં બિલ, રદ કરેલાં બિલ અને અગાઉના મહિનાનાં અમેન્ડમેન્ટ તેમાં નથી. તમારું GSTR-1 તમારી જવાબદારી છે; શંકા હોય તો તમારા એકાઉન્ટન્ટને પૂછો.

ગાઇડ

GSTR-1 ટેબલ સમજોકયું બિલ કયા ટેબલમાં જાય, ઉદાહરણ સાથે. GSTR-1 ની છેલ્લી તારીખ અને QRMPમાસિક, ક્વાર્ટરલી, IFF, GSTR-1A અને ત્રણ વર્ષની મર્યાદા. HSN સારાંશ (ટેબલ 12)અંક, B2B અને B2C ભાગ, UQC અને સામાન્ય ભૂલો. GST ઑફલાઇન ટૂલમાં ઇમ્પોર્ટExcel કે CSV થી ફાઇલ થયેલા GSTR-1 સુધી.

લોકો પૂછે છે તે પ્રશ્નો

શું આ મારું GSTR-1 ફાઇલ કરે છે?

ના. તે ફક્ત આંકડા અને ફાઇલો તૈયાર કરે છે. તમે તેને મફત GST ઑફલાઇન ટૂલમાં ઇમ્પોર્ટ કરો છો, JSON ફાઇલ તમારા પોતાના લૉગિનથી GST પોર્ટલ પર અપલોડ કરો છો અને ત્યાં જ ફાઇલ કરો છો.

બિલ ક્યાંથી આવે છે?

Nivesh Sahayak ડોક્યુમેન્ટ સાઇટ્સે (બિલિંગ, કૅશ મેમો, ક્રેડિટ નોટ, પહોંચ અને બીજી) આ બ્રાઉઝરમાં સેવ કરેલાં બિલમાંથી. બીજા સૉફ્ટવેરનાં બિલ તેમાં આવતાં નથી.

JSON ડાઉનલોડ કેમ નથી?

GST પોર્ટલનું JSON ફોર્મેટ સમયાંતરે બદલાય છે અને ફક્ત સત્તાવાર ઑફલાઇન ટૂલ જ તેની સાથે ચોક્કસ મેળ ખાય છે. તેથી અમે ઑફલાઇન ટૂલના પોતાના લેઆઉટમાં Excel અને CSV આપીએ છીએ અને JSON ટૂલ બનાવે છે.

કયાં બિલ B2C Large માં જાય છે?

બીજા રાજ્યના રજિસ્ટર્ડ ન હોય તેવા ખરીદનારને આપેલાં, ₹1 લાખથી વધુ બિલ રકમવાળાં બિલ (ઑગસ્ટ 2024 ના સમયગાળાથી; તે પહેલાં ₹2.5 લાખ). બાકીનાં બધાં B2C બિલ B2C Small માં ભેગાં ગણાય છે.

શું ક્વાર્ટરલી રિટર્ન માટે વાપરી શકાય?

હા. “એક ક્વાર્ટર (QRMP)” અને ક્વાર્ટરનો કોઈ પણ મહિનો પસંદ કરો; ત્રણેય મહિના સાથે લેવાય છે.

શું આ મફત છે?

હા, સંપૂર્ણ મફત. લૉગિન નથી અને બિલની કોઈ મર્યાદા નથી.
