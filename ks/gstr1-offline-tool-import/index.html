GSTR-1 › آف لائن ٹولس منٛز امپورٹ

GST آف لائن ٹولس منٛز امپورٹ کٔرِو تہٕ GSTR-1 فایِل کٔرِو

GST پورٹل چھُ نہٕ Excel سیدھ ہیوان۔ تمہِ ہند مفت Returns Offline Tool چھُ Excel یا CSV فایِلہ پرتھ JSON فایِل بناوان، تہٕ سُہ JSON چھوٚو تُہۍ اپ لوڈ کران۔ میکرکین فایِلن پیٹھ فایِل گمتس ریٹرنس تام چھُ یہِ پوٗرٕ راہ۔

اکھ وار: آف لائن ٹول ہیٚو

  1. www.gst.gov.in پیٹھ گژھِتھ Downloads › Offline Tools › Returns Offline Tool منٛز ڈاؤن لوڈ کٔرِو (یہِ صفحہ لیکھنہٕ وقت، 4 نومبر 2026 کس، آسہِ ورژن 3.2.4)۔
  2. زپ کھولِو تہٕ GST Offline Tool انسٹال کٔرِو۔ یہِ چھُ صرف Windows پیٹھ چلان۔ زپ منٛز چھِ سرکاری Excel ٹیمپلیٹ تہٕ نمونہ CSV فایِلہ تہِ۔

پرٛتھ مہینہ: JSON بنٲوِو

  1. GSTR-1 میکرس منٛز بزنس تہٕ مدت ژارِتھ دبٲوِو Excel ورک بُک (سورُے ٹیبل)۔ (یا پرٛتھ ٹیبلک الگ فایِل باپتھ سورُے CSV فایِلہ۔)
  2. آف لائن ٹول کھولِو، ژارِو New، ژارِو GSTR-1، لیکھِو پنُن GSTIN، مالی سال تہٕ ٹیکس مدت تہٕ دبٲوِو Proceed۔
  3. دبٲوِو Import Files۔ ورک بُک باپتھ ورتٲوِو Import Excel؛ CSV باپتھ سیکشن (مثلاً B2B) ژارِتھ ورتٲوِو Import CSV۔
  4. دبٲوِو View Summary تہٕ ٹوٹل ملٲوِو میکرکین ٹائلن سٕتۍ۔ ٹول چھُ ٹیکس ریٹ تہٕ ٹیکس لایق ویلیو پیٹھ کڈان؛ تُہُنٛدس بِلس پیٹھ ٹیکس آسہِ مختلف تہٕ ہیکو ٹیکسک رقم بدلٲوِتھ۔
  5. یم چیزہ فایِلہ ہیکن نہٕ ہیتھ یُن تم زالِو: ایکسپورٹ باپتھ پورٹ کوڈ تہٕ شپنگ بِل، تہٕ جاری کرنہٕ آمتۍ ڈاکیومنٹ تہٕ نِل ریٹڈ ٹیبل اگر ٹولن تم امپورٹ نہٕ کٔرۍ (تمہِ ہند ہیلپ شیٹ مطابق ہیکن یم دۅشوے ہاتھ سٕتۍ لیکھنہٕ پیوان)۔
  6. دبٲوِو Generate File۔ ٹول چھُ تُہُنٛدس کمپیوٹرس پیٹھ JSON فایِل سیو کران۔

GST پورٹلس پیٹھ: اپ لوڈ تہٕ فایِل

  1. لاگ اِن کٔرِو، گژھِو Services › Returns › Returns Dashboard تہٕ ژارِو سال تہٕ مدت۔
  2. GSTR-1 ٹائلس منٛز ژارِو Prepare Offline، پتہٕ Upload، تہٕ ژارِو JSON فایِل۔ ٹھہرِو تام یُس اسٹیٹس “processed” ہاوِ۔ ایرر آسہِ تہٕ ڈاؤن لوڈ کٔرِو ایرر فایِل، آف لائن ٹولس منٛز کھولِو، ٹھیک کٔرِو تہٕ دوبارٕ اپ لوڈ کٔرِو۔
  3. واپس گژھِتھ ژارِو Prepare Online تہٕ وُچھِو پرٛتھ ٹیبل۔ IRPس پیٹھ رجسٹر کرنہٕ آمتۍ ای-انوائس چھِ یتھ پانے پیوٚمتۍ آسان۔
  4. دبٲوِو Generate GSTR-1 Summary، وُچھِو، پتہٕ DSC یا EVC (OTP) سٕتۍ کٔرِو File Statement۔

کتھ لُکھ چھِ پھسان

  • ای-انوائس دۅن وارہ اپ لوڈ۔ اگر تُہِ ای-انوائسنگ چھوٚو ورتاوان، تیلہٕ چھِ تم بِل IRP پیٹھ پہلے GSTR-1 منٛز پیوٚمتۍ۔ سُہے انوائس نمبر دوبارٕ اپ لوڈ کرنہٕ پیٹھ چھُ اندراج بدلان؛ پانے بھرنہٕ آمتۍ اندراج وُچھِو، تمن دوبارٕ مَہ زالِو۔
  • تٲریخ۔ ٹولس چھیہ DD-MMM-YYYY (05-Nov-2026) پکان۔ میکر چھُ تٲریخ امہِ طریقہ لیکھان؛ Excel منٛز ایڈٹ کرنہٕ پیٹھ سیلز روزن ٹیکسٹ۔
  • ریاستھ۔ پلیس آف سپلائی پکِ بالکل ٹولک لسٹ ہِشہٕ "03-Punjab" لیکھنہٕ آسُن۔
  • پرانۍ ٹیمپلیٹ۔ آف لائن ٹولک نوو ورژن اگر نوو ٹیمپلیٹ منگہِ، تیلہٕ کاپی کٔرِو سانین ورک بُکک قطارہ نوٚین ٹیمپلیٹک تِمو شیٹن منٛز یمن ہند ناو چھُ سُہے۔
  • بیٚین سافٹ ویئرن ہنٛز بِل۔ میکر چھُ صرف Nivesh Sahayak منٛز سیو کرنہٕ آمتۍ بِل زانان۔ JSON بنناہ برونٛہہ بیاکھ بِل زالِو آف لائن ٹولس منٛز۔
