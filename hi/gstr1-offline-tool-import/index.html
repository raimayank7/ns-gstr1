GSTR-1 › ऑफ़लाइन टूल में इम्पोर्ट

GST ऑफ़लाइन टूल में इम्पोर्ट करें और GSTR-1 फ़ाइल करें

GST पोर्टल Excel सीधे नहीं लेता। उसका फ्री Returns Offline Tool Excel या CSV फ़ाइलें पढ़कर JSON फ़ाइल बनाता है, और वही JSON आप अपलोड करते हैं। मेकर की फ़ाइलों से फ़ाइल हुए रिटर्न तक का पूरा रास्ता यहाँ है।

एक बार: ऑफ़लाइन टूल लें

  1. www.gst.gov.in पर Downloads › Offline Tools › Returns Offline Tool में जाकर उसे डाउनलोड करें (यह पेज लिखते समय, 4 नवंबर 2026 को, वर्शन 3.2.4 था)।
  2. उसे अनज़िप करें और GST Offline Tool इंस्टॉल करें। यह सिर्फ़ Windows पर चलता है। ज़िप में सरकारी Excel टेम्पलेट और सैंपल CSV फ़ाइलें भी होती हैं।

हर महीने: JSON बनाएँ

  1. GSTR-1 मेकर में बिज़नेस और अवधि चुनें और Excel वर्कबुक (सभी टेबल) दबाएँ। (या हर टेबल की अलग फ़ाइल के लिए सभी CSV फ़ाइलें।)
  2. ऑफ़लाइन टूल खोलें, New चुनें, GSTR-1 चुनें, अपना GSTIN, फ़ाइनेंशियल ईयर और टैक्स पीरियड लिखें, और Proceed दबाएँ।
  3. Import Files दबाएँ। वर्कबुक के लिए Import Excel इस्तेमाल करें; CSV के लिए सेक्शन चुनें (जैसे B2B) और Import CSV इस्तेमाल करें।
  4. View Summary दबाएँ और टोटल को मेकर की टाइल्स से मिलाएँ। टूल टैक्स रेट और टैक्सेबल वैल्यू से निकालता है; आपके बिल में कोई और टैक्स रकम है तो आप उसे बदल सकते हैं।
  5. वह जोड़ें जो फ़ाइलों में नहीं आ सकता: एक्सपोर्ट के लिए पोर्ट कोड और शिपिंग बिल, और जारी डॉक्यूमेंट व निल रेटेड टेबल अगर टूल ने इम्पोर्ट नहीं कीं (उसकी हेल्प शीट कहती है कि इन दोनों को हाथ से भरना पड़ सकता है)।
  6. Generate File दबाएँ। टूल आपके कंप्यूटर पर एक JSON फ़ाइल सेव करता है।

GST पोर्टल पर: अपलोड करें और फ़ाइल करें

  1. लॉगिन करें, Services › Returns › Returns Dashboard में जाएँ, साल और अवधि चुनें।
  2. GSTR-1 टाइल में Prepare Offline चुनें, फिर Upload, और JSON फ़ाइल चुनें। तब तक रुकें जब तक स्टेटस में न दिखे कि प्रोसेस हो गई। एरर दिखें तो एरर फ़ाइल डाउनलोड करें, ऑफ़लाइन टूल में खोलें, ठीक करें और फिर अपलोड करें।
  3. वापस जाएँ, Prepare Online चुनें और हर टेबल जाँचें। IRP पर रजिस्टर किए ई-इनवॉइस यहाँ अपने-आप दिख जाते हैं।
  4. Generate GSTR-1 Summary दबाएँ, उसे जाँचें, फिर DSC या EVC (OTP) से File Statement करें।

जहाँ लोग अटकते हैं

  • ई-इनवॉइस दो बार अपलोड। अगर आप ई-इनवॉइसिंग करते हैं तो वे बिल IRP से पहले ही GSTR-1 में होते हैं। वही इनवॉइस नंबर दोबारा अपलोड करने से एंट्री बदल जाती है; अपने-आप भरी एंट्री जाँचें, उन्हें फिर से न जोड़ें।
  • तारीख। टूल को DD-MMM-YYYY (05-Nov-2026) चाहिए। मेकर तारीखें इसी तरह लिखता है; Excel में बदलाव करें तो सेल टेक्स्ट ही रहने दें।
  • राज्य। प्लेस ऑफ़ सप्लाई "03-Punjab" की तरह ही लिखा होना चाहिए, ठीक वैसे जैसे टूल की लिस्ट में है।
  • पुराना टेम्पलेट। ऑफ़लाइन टूल का आगे का वर्शन नया टेम्पलेट माँगे तो हमारी वर्कबुक की पंक्तियाँ नए टेम्पलेट की उन्हीं नामों वाली शीट में कॉपी कर दें।
  • दूसरे सॉफ़्टवेयर के बिल। मेकर सिर्फ़ Nivesh Sahayak में सेव बिल जानता है। JSON बनाने से पहले दूसरे बिल ऑफ़लाइन टूल में जोड़ें।
इस महीने के बिल अभी GSTR-1 में छाँटें।मेकर खोलें
