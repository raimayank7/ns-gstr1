GSTR-1 › ஆஃப்லைன் டூல் இம்போர்ட்

GST ஆஃப்லைன் டூலில் இம்போர்ட் செய்து GSTR-1 ஃபைல் செய்யுங்கள்

GST போர்ட்டல் Excel-ஐ நேரடியாக ஏற்காது. அதன் இலவச Returns Offline Tool Excel அல்லது CSV ஃபைல்களைப் படித்து JSON ஃபைலை உருவாக்கும்; அந்த JSON-ஐத்தான் நீங்கள் அப்லோட் செய்கிறீர்கள். மேக்கரின் ஃபைல்களிலிருந்து ஃபைல் செய்த ரிட்டர்ன் வரை முழு வழி இதோ.

ஒரு முறை: ஆஃப்லைன் டூலைப் பெறுங்கள்

  1. www.gst.gov.in-இல் Downloads › Offline Tools › Returns Offline Tool என்பதற்குச் சென்று டவுன்லோட் செய்யுங்கள் (இந்த பக்கம் எழுதப்பட்டபோது, 4 நவம்பர் 2026, பதிப்பு 3.2.4).
  2. Zip-ஐ அன்சிப் செய்து GST Offline Tool-ஐ இன்ஸ்டால் செய்யுங்கள். இது Windows-இல் மட்டுமே ஓடும். Zip-இல் அதிகாரப்பூர்வ Excel டெம்ப்ளேட்டும் மாதிரி CSV ஃபைல்களும் உள்ளன.

ஒவ்வொரு மாதமும்: JSON உருவாக்குங்கள்

  1. GSTR-1 மேக்கரில் பிசினஸையும் காலத்தையும் தேர்ந்தெடுத்து Excel வொர்க்புக் (எல்லா டேபிள்களும்) என்பதை அழுத்துங்கள். (அல்லது ஒவ்வொரு டேபிளுக்கும் ஒரு ஃபைலுக்கு எல்லா CSV ஃபைல்களும்.)
  2. ஆஃப்லைன் டூலைத் திறந்து New தேர்ந்தெடுத்து, GSTR-1 தேர்ந்தெடுத்து, உங்கள் GSTIN, நிதியாண்டு, வரிக் காலத்தை டைப் செய்து, Proceed அழுத்துங்கள்.
  3. Import Files அழுத்துங்கள். வொர்க்புக்குக்கு Import Excel பயன்படுத்துங்கள்; CSV-க்கு பிரிவைத் (உதாரணம் B2B) தேர்ந்தெடுத்து Import CSV பயன்படுத்துங்கள்.
  4. View Summary அழுத்தி, மொத்தங்களை மேக்கரின் டைல்களுடன் ஒப்பிடுங்கள். டூல் வரி விகிதம் மற்றும் வரி விதிக்கத்தக்க மதிப்பிலிருந்து வரியைக் கணக்கிடும்; உங்கள் பில்லில் வேறு தொகை இருந்தால் வரித் தொகையைத் திருத்தலாம்.
  5. ஃபைல்களில் வராதவற்றைச் சேர்க்கவும்: ஏற்றுமதிகளுக்கான போர்ட் கோடு மற்றும் ஷிப்பிங் பில், மேலும் டூல் இம்போர்ட் செய்யவில்லை என்றால் வழங்கிய டாக்குமெண்டுகள் மற்றும் nil-rated டேபிள்கள் (இந்த இரண்டையும் கையால் டைப் செய்ய வேண்டியிருக்கலாம் என்று அதன் உதவி ஷீட் சொல்கிறது).
  6. Generate File அழுத்துங்கள். டூல் உங்கள் கம்ப்யூட்டரில் ஒரு JSON ஃபைலை சேவ் செய்யும்.

GST போர்ட்டலில்: அப்லோட் செய்து ஃபைல் செய்யுங்கள்

  1. லாகின் செய்து, Services › Returns › Returns Dashboard சென்று, ஆண்டையும் காலத்தையும் தேர்ந்தெடுங்கள்.
  2. GSTR-1 டைலில் Prepare Offline, பிறகு Upload தேர்ந்தெடுத்து JSON ஃபைலைத் தேர்ந்தெடுங்கள். ஸ்டேட்டஸ் processed என்று வரும் வரை காத்திருங்கள். பிழைகள் காட்டினால் எரர் ஃபைலை டவுன்லோட் செய்து, ஆஃப்லைன் டூலில் திறந்து, திருத்தி, மீண்டும் அப்லோட் செய்யுங்கள்.
  3. திரும்பி வந்து Prepare Online தேர்ந்தெடுத்து ஒவ்வொரு டேபிளையும் பாருங்கள். IRP-இல் நீங்கள் பதிவு செய்த இ-இன்வாய்ஸ்கள் இங்கே ஏற்கெனவே தானாகவே தெரியும்.
  4. Generate GSTR-1 Summary அழுத்தி, சரிபார்த்து, பிறகு DSC அல்லது EVC (OTP) மூலம் File Statement செய்யுங்கள்.

மக்கள் தடுமாறும் இடங்கள்

  • இ-இன்வாய்ஸ் இரண்டு முறை அப்லோட் ஆவது. இ-இன்வாய்சிங் பயன்படுத்தினால், அந்த பில்கள் IRP-யிலிருந்து ஏற்கெனவே GSTR-1-இல் உள்ளன. அதே இன்வாய்ஸ் நம்பரை மீண்டும் அப்லோட் செய்தால் பதிவு மாற்றப்படும்; தானாக நிரம்பியவற்றை மீண்டும் சேர்க்காமல் சரிபாருங்கள்.
  • தேதிகள். டூல் DD-MMM-YYYY கேட்கும் (05-Nov-2026). மேக்கர் தேதிகளை இப்படியே எழுதுகிறது; Excel-இல் திருத்தினால் செல்களை டெக்ஸ்ட்டாகவே வையுங்கள்.
  • மாநிலங்கள். சப்ளை இடம் டூலின் பட்டியலில் உள்ளபடியே "03-Punjab" என்று எழுதப்பட வேண்டும்.
  • பழைய டெம்ப்ளேட். ஆஃப்லைன் டூலின் எதிர்கால பதிப்பு புதிய டெம்ப்ளேட் கேட்டால், எங்கள் வொர்க்புக்கின் வரிசைகளை புதிய டெம்ப்ளேட்டின் அதே பெயருடைய ஷீட்டுகளுக்கு காப்பி செய்யுங்கள்.
  • வேறு சாஃப்ட்வேரில் போட்ட பில்கள். மேக்கருக்கு Nivesh Sahayak-இல் சேவ் ஆன பில்கள் மட்டுமே தெரியும். JSON உருவாக்குவதற்கு முன் மற்ற பில்களை ஆஃப்லைன் டூலில் சேர்க்கவும்.
இந்த மாதத்து பில்களை இப்போதே GSTR-1-ஆகப் பிரியுங்கள்.மேக்கரைத் திறக்கவும்
