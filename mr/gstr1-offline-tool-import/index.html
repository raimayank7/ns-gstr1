GSTR-1 › ऑफलाइन टूल इम्पोर्ट

GST ऑफलाइन टूलमध्ये इम्पोर्ट करा आणि GSTR-1 फाइल करा

GST पोर्टल Excel थेट स्वीकारत नाही. त्याचे मोफत Returns Offline Tool Excel किंवा CSV फाइल वाचून JSON फाइल बनवते, आणि तीच JSON तुम्ही अपलोड करता. मेकरच्या फाइलपासून फाइल झालेल्या रिटर्नपर्यंतचा संपूर्ण मार्ग इथे आहे.

एकदाच: ऑफलाइन टूल मिळवा

  1. www.gst.gov.in वर Downloads › Offline Tools › Returns Offline Tool मध्ये जाऊन ते डाउनलोड करा (हे पेज लिहिताना, 4 नोव्हेंबर 2026 रोजी, आवृत्ती 3.2.4).
  2. झिप उघडा आणि GST Offline Tool इन्स्टॉल करा. ते फक्त Windows वर चालते. झिपमध्ये अधिकृत Excel टेम्पलेट आणि नमुना CSV फाइलही असतात.

दर महिन्याला: JSON बनवा

  1. GSTR-1 मेकरमध्ये बिझनेस आणि कालावधी निवडा आणि Excel वर्कबुक (सर्व टेबल) दाबा. (किंवा प्रत्येक टेबलची वेगळी फाइल हवी असेल तर सर्व CSV फाइल.)
  2. ऑफलाइन टूल उघडा, New निवडा, GSTR-1 निवडा, तुमचा GSTIN, आर्थिक वर्ष आणि टॅक्स कालावधी टाका आणि Proceed दाबा.
  3. Import Files दाबा. वर्कबुकसाठी Import Excel वापरा; CSV साठी विभाग (उदा. B2B) निवडा आणि Import CSV वापरा.
  4. View Summary दाबा आणि एकूण आकडे मेकरच्या टाइल्सशी जुळवा. टूल दर आणि टॅक्सेबल व्हॅल्यूवरून टॅक्स काढते; तुमच्या बिलावर वेगळी रक्कम असेल तर टॅक्सची रक्कम तुम्ही बदलू शकता.
  5. फाइलमध्ये जे येऊ शकत नाही ते जोडा: एक्सपोर्टसाठी पोर्ट कोड आणि शिपिंग बिल, आणि दिलेली डॉक्युमेंट व निल रेटेड टेबल जर टूलने इम्पोर्ट केले नसतील (त्याच्या हेल्प शीटनुसार ही दोन टाइप करावी लागू शकतात).
  6. Generate File दाबा. टूल तुमच्या कॉम्प्युटरवर JSON फाइल सेव्ह करते.

GST पोर्टलवर: अपलोड करा आणि फाइल करा

  1. लॉगिन करा, Services › Returns › Returns Dashboard मध्ये जा, वर्ष आणि कालावधी निवडा.
  2. GSTR-1 टाइलमध्ये Prepare Offline, मग Upload निवडा आणि JSON फाइल निवडा. स्टेटस “processed” होईपर्यंत थांबा. एरर दिसल्या तर एरर फाइल डाउनलोड करा, ऑफलाइन टूलमध्ये उघडा, दुरुस्त करा आणि पुन्हा अपलोड करा.
  3. मागे जा, Prepare Online निवडा आणि प्रत्येक टेबल तपासा. IRP वर रजिस्टर केलेली ई-इनव्हॉइस इथे आपोआप दिसतात.
  4. Generate GSTR-1 Summary दाबा, तपासा, मग DSC किंवा EVC (OTP) ने File Statement करा.

लोक नेमके कुठे अडतात

  • ई-इनव्हॉइस दोनदा अपलोड. तुम्ही ई-इनव्हॉइसिंग वापरत असाल तर ती बिले IRP वरून आधीच GSTR-1 मध्ये आलेली असतात. तोच इनव्हॉइस नंबर पुन्हा अपलोड केल्यास एंट्री बदलली जाते; आपोआप भरलेल्या एंट्री पुन्हा न जोडता त्या तपासा.
  • तारखा. टूलला DD-MMM-YYYY (05-Nov-2026) हवे. मेकर तारखा असे लिहितो; Excel मध्ये बदल करताना सेल टेक्स्ट म्हणूनच ठेवा.
  • राज्ये. प्लेस ऑफ सप्लाय टूलच्या यादीप्रमाणेच "03-Punjab" असा लिहावा.
  • जुने टेम्पलेट. ऑफलाइन टूलची पुढची आवृत्ती नवे टेम्पलेट मागत असेल तर आमच्या वर्कबुकमधील ओळी नव्या टेम्पलेटच्या त्याच नावाच्या शीटमध्ये कॉपी करा.
  • दुसऱ्या सॉफ्टवेअरमधील बिले. मेकरला फक्त Nivesh Sahayak मध्ये सेव्ह केलेली बिले माहीत असतात. JSON बनवण्यापूर्वी इतर बिले ऑफलाइन टूलमध्ये जोडा.
