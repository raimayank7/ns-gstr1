अपन बिल सँ फ्री GSTR-1 समरी

अपन बिज़नेस आ मास चुनू। Nivesh Sahayak क डॉक्यूमेंट साइट पर अहाँ जे किछु GST बिल आ क्रेडिट नोट सेव कएने छी, से GSTR-1 क टेबल मे छँटि जाइत अछि, टोटल आ चेतावनीक संग, आ GST Returns Offline Tool क लेल फ़ाइल तैयार भेटैत अछि। ने लॉगिन, ने किछु अपलोड।

एतय GSTR-1 समरी कोना बनाउ

  1. पहिने एतय अपन बिल बनाउ। billing.niveshsahayak.in पर टैक्स इनवॉइस, GST वाला कैश मेमो, आ credit-note.niveshsahayak.in पर क्रेडिट वा डेबिट नोट एहि ब्राउज़र मे सेव होइत अछि। ई पेज ओकरा सभ केँ पढ़ि लैत अछि; अहाँ केँ किछु फेर नहि लिखबाक अछि।
  2. बिज़नेस आ अवधि चुनू। एक मास चुनू, वा QRMP स्कीम मे छी तँ एक तिमाही। अपन टर्नओवर बैंड सेहो चुनू, जाहि सँ HSN कोडक अंकक सही जाँच होअय।
  3. चेतावनी पढ़ू। HSN कोडक कमी, कीनएवालाक गलत GSTIN, नंबर सीरीज़क गैप, आ ओ नोट जकर ओरिजिनल इनवॉइस सेव नहि अछि, सभ ऊपर लिखल अबैत अछि। बिल केँ ओकर अपन साइट पर ठीक करू, फेर सेव कएल बिल फेर सँ पढ़ू दबाउ।
  4. हर टेबल जाँचू। B2B बिल कीनएवालाक GSTIN क संग एक-एक क’ क’ देखाइत अछि; छोट B2C बिक्री राज्य आ रेट क हिसाबे जोड़ल जाइत अछि; HSN समरी B2B आ B2C मे बँटल रहैत अछि, जेना पोर्टल आब मँगैत अछि।
  5. फ़ाइल डाउनलोड करू। Excel वर्कबुक (सभ टेबल) ऑफ़लाइन टूलक शीटक नाम वाला एक फ़ाइल दैत अछि; सभ CSV फ़ाइल हर टेबलक एक फ़ाइल दैत अछि, टूलक अपन हेडरक संग।
  6. JSON बनाउ आ फ़ाइल करू। फ़ाइल GST Returns Offline Tool मे इम्पोर्ट करू, JSON बनाउ, GST पोर्टल पर GSTR-1 मे अपलोड करू, ओतय समरी जाँचू आ फ़ाइल करू। देखू ऑफ़लाइन टूल मे इम्पोर्ट कोना करू।

ई अहाँक लेल की करैत अछि

  • हर बिल अपने-आप छाँटैत अछि: कीनएवालाक GSTIN, राज्य आ बिल वैल्यूक हिसाबे, टेबल 4, 5, 6A, 7, 8, 9B, 11A, 12 आ 13 मे।
  • B2C Large क ₹1 लाखक सीमा अगस्त 2024 क अवधिक बादक बिल लेल, आ पुरान बिल लेल पुरान ₹2.5 लाखक सीमा लगबैत अछि।
  • क्रेडिट आ डेबिट नोट सम्हारैत अछि: रजिस्टर्ड कीनएवाला केँ नोट 9B मे, आ छोट B2C बिलक नोट सँ B2CS क आँकड़ा घटबैत वा बढ़बैत अछि, जेना रिटर्न मे चाही।
  • HSN समरी दू हिस्सा मे, B2B आ B2C, रेट, मात्रा आ पोर्टल केँ मंज़ूर यूनिट कोड (UQC) क संग; सर्विस (SAC 99…) मे मात्रा नहि पड़ैत अछि।
  • जारी डॉक्यूमेंट (टेबल 13): हर नंबर सीरीज़क पहिल आ अंतिम नंबर आ कुल, आ नंबर छूटलापर वा दोहराओल गेलापर चेतावनी।
  • ऑफ़लाइन टूलक लेआउट: हेडर GST Returns Offline Tool V3.2.4 क फ़ाइल सँ लेल गेल अछि, तारीख DD-MMM-YYYY मे आ राज्य "07-Delhi" जकाँ।

अहाँक डेटा अहाँ लग रहैत अछि

समरी एहि ब्राउज़र मे, अहाँक Nivesh Sahayak डेटा होम (my.niveshsahayak.in) मे सेव बिल सँ बनैत अछि। हमरा सभ केँ वा GST पोर्टल केँ किछु नहि पठाओल जाइत अछि। रिटर्न अहाँ अपने अपन लॉगिन सँ अपलोड करैत छी।

फ़ाइल करबा सँ पहिने जाँचि लिअ। ई अहाँक अपन बिल सँ बनल वर्किंग शीट अछि। आन सॉफ़्टवेयर मे बनल बिल, कैंसल बिल आ पछिला मासक अमेंडमेंट एहि मे नहि अछि। अहाँक GSTR-1 अहाँक जिम्मेदारी अछि; शक होअय तँ अपन अकाउंटेंट सँ पूछू।

गाइड

GSTR-1 क टेबल बुझूकोन बिल कोन टेबल मे जाइत अछि, उदाहरणक संग। GSTR-1 क अंतिम तारीख आ QRMPमासिक, तिमाही, IFF, GSTR-1A आ तीन सालक सीमा। HSN समरी (टेबल 12)अंक, B2B आ B2C हिस्सा, UQC आ आम गलती। GST ऑफ़लाइन टूल मे इम्पोर्टExcel वा CSV सँ फ़ाइल भेल GSTR-1 धरि।

लोक की पूछैत अछि

की एहि सँ हमर GSTR-1 फ़ाइल भ’ जाइत अछि?

नहि। ई मात्र आँकड़ा आ फ़ाइल तैयार करैत अछि। अहाँ ओकरा सभ केँ फ्री GST ऑफ़लाइन टूल मे इम्पोर्ट करैत छी, अपन लॉगिन सँ GST पोर्टल पर JSON अपलोड करैत छी आ ओतहि फ़ाइल करैत छी।

बिल कतय सँ अबैत अछि?

एहि ब्राउज़र मे Nivesh Sahayak क डॉक्यूमेंट साइट (बिलिंग, कैश मेमो, क्रेडिट नोट, रसीद आदि) सँ सेव कएल बिल सँ। आन सॉफ़्टवेयरक बिल एहि मे शामिल नहि अछि।

JSON डाउनलोड किएक नहि अछि?

GST पोर्टलक JSON फ़ॉर्मेट समय-समय पर बदलैत रहैत अछि आ मात्र सरकारी ऑफ़लाइन टूल टा ओकरा सँ पक्का मेल खाइत अछि। तेँ हम सभ ऑफ़लाइन टूलक अपन लेआउट मे Excel आ CSV दैत छी आ JSON टूल बनबैत अछि।

कोन बिल B2C Large मे जाइत अछि?

आन राज्यक बिना-रजिस्ट्रेशन वाला कीनएवाला केँ ₹1 लाख सँ ऊपरक बिल वैल्यू वाला बिल (अगस्त 2024 क अवधि सँ; ओहि सँ पहिने ₹2.5 लाख)। बाँकी सभ B2C बिल B2C Small मे जोड़ि देल जाइत अछि।

की एकरा तिमाही रिटर्नक लेल इस्तेमाल क’ सकैत छी?

हँ। "एक तिमाही (QRMP)" चुनू आ तिमाहीक कोनो मास चुनू; तीनू मास संगहि लेल जाइत अछि।

की ई फ्री अछि?

हँ, एकदम फ्री अछि। ने लॉगिन चाही, ने बिलक कोनो सीमा अछि।
