GSTR-1 › ऑफ़लाइन टूल मे इम्पोर्ट

GST ऑफ़लाइन टूल मे इम्पोर्ट करू आ GSTR-1 फ़ाइल करू

GST पोर्टल Excel सीधे नहि लैत अछि। ओकर फ्री Returns Offline Tool Excel वा CSV फ़ाइल पढ़ि कए JSON फ़ाइल बनबैत अछि, आ वएह JSON अहाँ अपलोड करैत छी। मेकरक फ़ाइल सँ फ़ाइल भेल रिटर्न धरिक पूरा बाट एतय अछि।

एक बेर: ऑफ़लाइन टूल लिअ

  1. www.gst.gov.in पर Downloads › Offline Tools › Returns Offline Tool मे जा कए ओकरा डाउनलोड करू (ई पेज लिखैत काल, 4 नवंबर 2026 केँ, वर्शन 3.2.4 छल)।
  2. ओकरा अनज़िप करू आ GST Offline Tool इंस्टॉल करू। ई मात्र Windows पर चलैत अछि। ज़िप मे सरकारी Excel टेम्पलेट आ सैंपल CSV फ़ाइल सेहो रहैत अछि।

हर मास: JSON बनाउ

  1. GSTR-1 मेकर मे बिज़नेस आ अवधि चुनू आ Excel वर्कबुक (सभ टेबल) दबाउ। (वा हर टेबलक अलग फ़ाइलक लेल सभ CSV फ़ाइल।)
  2. ऑफ़लाइन टूल खोलू, New चुनू, GSTR-1 चुनू, अपन GSTIN, फ़ाइनेंशियल ईयर आ टैक्स पीरियड लिखू, आ Proceed दबाउ।
  3. Import Files दबाउ। वर्कबुकक लेल Import Excel इस्तेमाल करू; CSV क लेल सेक्शन चुनू (जेना B2B) आ Import CSV इस्तेमाल करू।
  4. View Summary दबाउ आ टोटल केँ मेकरक टाइल सँ मिलाउ। टूल टैक्स रेट आ टैक्सेबल वैल्यू सँ निकालैत अछि; अहाँक बिल मे कोनो आन टैक्स रकम अछि तँ अहाँ ओकरा बदलि सकैत छी।
  5. ओ जोड़ू जे फ़ाइल मे नहि आबि सकैत अछि: एक्सपोर्टक लेल पोर्ट कोड आ शिपिंग बिल, आ जारी डॉक्यूमेंट व निल रेटेड टेबल जँ टूल इम्पोर्ट नहि कएलक (ओकर हेल्प शीट कहैत अछि जे एहि दुनू केँ हाथ सँ भरऽ पड़ि सकैत अछि)।
  6. Generate File दबाउ। टूल अहाँक कंप्यूटर पर एक JSON फ़ाइल सेव करैत अछि।

GST पोर्टल पर: अपलोड करू आ फ़ाइल करू

  1. लॉगिन करू, Services › Returns › Returns Dashboard मे जाउ, साल आ अवधि चुनू।
  2. GSTR-1 टाइल मे Prepare Offline चुनू, फेर Upload, आ JSON फ़ाइल चुनू। तावत रुकू जावत स्टेटस मे नहि देखाय जे प्रोसेस भ’ गेल। एरर देखाय तँ एरर फ़ाइल डाउनलोड करू, ऑफ़लाइन टूल मे खोलू, ठीक करू आ फेर अपलोड करू।
  3. वापस जाउ, Prepare Online चुनू आ हर टेबल जाँचू। IRP पर रजिस्टर कएल ई-इनवॉइस एतय अपने-आप देखा जाइत अछि।
  4. Generate GSTR-1 Summary दबाउ, ओकरा जाँचू, फेर DSC वा EVC (OTP) सँ File Statement करू।

जतय लोक अटकैत अछि

  • ई-इनवॉइस दू बेर अपलोड। जँ अहाँ ई-इनवॉइसिंग करैत छी तँ ओ बिल IRP सँ पहिनहि GSTR-1 मे रहैत अछि। वएह इनवॉइस नंबर फेर अपलोड कएने एंट्री बदलि जाइत अछि; अपने-आप भरल एंट्री जाँचू, ओकरा सभ केँ फेर नहि जोड़ू।
  • तारीख। टूल केँ DD-MMM-YYYY (05-Nov-2026) चाही। मेकर तारीख एहिना लिखैत अछि; Excel मे बदलाव करी तँ सेल टेक्स्ट टा रहय दिअ।
  • राज्य। प्लेस ऑफ़ सप्लाई "03-Punjab" जकाँ टा लिखल हेबाक चाही, ठीक ओहिना जेना टूलक लिस्ट मे अछि।
  • पुरान टेम्पलेट। ऑफ़लाइन टूलक आगुक वर्शन नव टेम्पलेट मँगय तँ हमरा सभक वर्कबुकक पंक्ति नव टेम्पलेटक ओहि नाम वाला शीट मे कॉपी क’ दिअ।
  • आन सॉफ़्टवेयरक बिल। मेकर मात्र Nivesh Sahayak मे सेव बिल जनैत अछि। JSON बनेबा सँ पहिने आन बिल ऑफ़लाइन टूल मे जोड़ू।
एहि मासक बिल एखनहि GSTR-1 मे छाँटू।मेकर खोलू
