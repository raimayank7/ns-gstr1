GSTR-1 › অফলাইন টুলে ইমপোর্ট

GST অফলাইন টুলে ইমপোর্ট করে GSTR-1 ফাইল করুন

GST পোর্টাল সরাসরি Excel নেয় না। তার ফ্রি Returns Offline Tool Excel বা CSV ফাইল পড়ে JSON ফাইল বানায়, আর আপলোড করতে হয় সেই JSON। মেকারের ফাইল থেকে ফাইল করা রিটার্ন পর্যন্ত পুরো পথটা এখানে।

একবারই: অফলাইন টুল নিন

  1. www.gst.gov.in-এ গিয়ে Downloads › Offline Tools › Returns Offline Tool খুলে নামান (এই পেজ লেখার সময়, 4 নভেম্বর 2026-এ, ভার্সন ছিল 3.2.4)।
  2. জিপ খুলে GST Offline Tool ইনস্টল করুন। এটা শুধু Windows-এ চলে। জিপে সরকারি Excel টেমপ্লেট আর নমুনা CSV ফাইলও থাকে।

প্রতি মাসে: JSON বানান

  1. GSTR-1 মেকারে ব্যবসা আর পিরিয়ড বেছে Excel ওয়ার্কবুক (সব টেবিল) চাপুন। (অথবা প্রতি টেবিলের একটি করে ফাইলের জন্য সব CSV ফাইল।)
  2. অফলাইন টুল খুলে New বেছে নিন, GSTR-1 নির্বাচন করুন, আপনার GSTIN, ফিনান্সিয়াল ইয়ার আর ট্যাক্স পিরিয়ড লিখে Proceed চাপুন।
  3. Import Files চাপুন। ওয়ার্কবুকের জন্য Import Excel; CSV হলে সেকশন (যেমন B2B) বেছে Import CSV ব্যবহার করুন।
  4. View Summary চাপুন আর মোট অঙ্কগুলো মেকারের টাইলের সঙ্গে মিলিয়ে নিন। টুল রেট আর ট্যাক্সেবল ভ্যালু থেকে ট্যাক্স হিসাব করে; আপনার বিলে অন্য অঙ্ক থাকলে ট্যাক্সের অঙ্ক বদলাতে পারেন।
  5. ফাইল যা বহন করতে পারে না তা যোগ করুন: এক্সপোর্টের জন্য পোর্ট কোড আর শিপিং বিল, আর ইস্যু করা ডকুমেন্ট ও নিল রেটেড টেবিল যদি টুল ইমপোর্ট না করে থাকে (টুলের হেল্প শিট বলে এই দুটো হাতে লিখতে হতে পারে)।
  6. Generate File চাপুন। টুল আপনার কম্পিউটারে একটি JSON ফাইল সেভ করে।

GST পোর্টালে: আপলোড ও ফাইল

  1. লগইন করে Services › Returns › Returns Dashboard-এ যান, বছর আর পিরিয়ড বেছে নিন।
  2. GSTR-1 টাইলে Prepare Offline বেছে Upload চাপুন আর JSON ফাইলটি দিন। স্ট্যাটাসে প্রসেস হয়েছে লেখা না আসা পর্যন্ত অপেক্ষা করুন। ভুল দেখালে এরর ফাইল নামান, অফলাইন টুলে খুলে ঠিক করে আবার আপলোড করুন।
  3. ফিরে এসে Prepare Online বেছে প্রতিটি টেবিল দেখে নিন। IRP-তে আপনার রেজিস্টার করা e-invoice এখানে নিজেই এসে যায়।
  4. Generate GSTR-1 Summary চাপুন, দেখে নিন, তারপর DSC বা EVC (OTP) দিয়ে File Statement করুন।

যেখানে লোকে আটকে যায়

  • e-invoice দুইবার আপলোড। e-invoicing করলে সেই বিল IRP থেকে আগেই GSTR-1-এ আছে। একই ইনভয়েস নম্বর আবার আপলোড করলে এন্ট্রি বদলে যায়; নিজে আবার যোগ না করে অটো-ভরা এন্ট্রিগুলো দেখে নিন।
  • তারিখ। টুল চায় DD-MMM-YYYY (05-Nov-2026)। মেকার এভাবেই তারিখ লেখে; Excel-এ বদলালে ঘরগুলো টেক্সট রাখুন।
  • রাজ্য। প্লেস অফ সাপ্লাই লিখতে হবে "03-Punjab" ধরনে, টুলের তালিকার মতো হুবহু।
  • পুরনো টেমপ্লেট। অফলাইন টুলের ভবিষ্যৎ ভার্সন নতুন টেমপ্লেট চাইলে আমাদের ওয়ার্কবুকের সারিগুলো একই নামের শিটে নতুন টেমপ্লেটে কপি করুন।
  • অন্য সফটওয়্যারের বিল। মেকার শুধু Nivesh Sahayak-এ সেভ করা বিল চেনে। JSON বানানোর আগে অন্য বিলগুলো অফলাইন টুলে যোগ করুন।
এই মাসের বিল এখনই GSTR-1-এ সাজিয়ে নিন।মেকার খুলুন
