GSTR-1 › ఆఫ్‌లైన్ టూల్ ఇంపోర్ట్

GST ఆఫ్‌లైన్ టూల్‌లో ఇంపోర్ట్ చేసి GSTR-1 ఫైల్ చేయండి

GST పోర్టల్ Excelను నేరుగా తీసుకోదు. దాని ఉచిత Returns Offline Tool Excel లేదా CSV ఫైళ్లను చదివి JSON ఫైల్ తయారుచేస్తుంది, ఆ JSONనే మీరు అప్‌లోడ్ చేస్తారు. మేకర్ ఫైళ్ల నుంచి ఫైల్ చేసిన రిటర్న్ వరకు మొత్తం దారి ఇదిగో.

ఒకసారి: ఆఫ్‌లైన్ టూల్ తెచ్చుకోండి

  1. www.gst.gov.inలో Downloads › Offline Tools › Returns Offline Tool కి వెళ్లి డౌన్‌లోడ్ చేయండి (ఈ పేజీ రాసినప్పుడు, 4 నవంబర్ 2026న, వెర్షన్ 3.2.4).
  2. Zipను అన్‌జిప్ చేసి GST Offline Tool ఇన్‌స్టాల్ చేయండి. ఇది Windowsలో మాత్రమే నడుస్తుంది. Zipలో అధికారిక Excel టెంప్లేట్, నమూనా CSV ఫైళ్లు కూడా ఉన్నాయి.

ప్రతి నెలా: JSON తయారుచేయండి

  1. GSTR-1 మేకర్‌లో బిజినెస్‌ను, కాలాన్ని ఎంచుకుని Excel వర్క్‌బుక్ (అన్ని టేబుళ్లు) నొక్కండి. (లేదా ప్రతి టేబుల్‌కు ఒక ఫైల్ కోసం అన్ని CSV ఫైళ్లు.)
  2. ఆఫ్‌లైన్ టూల్ తెరిచి New ఎంచుకుని, GSTR-1 ఎంచుకుని, మీ GSTIN, ఆర్థిక సంవత్సరం, పన్ను కాలం టైప్ చేసి, Proceed నొక్కండి.
  3. Import Files నొక్కండి. వర్క్‌బుక్‌కు Import Excel వాడండి; CSVకి విభాగాన్ని (ఉదాహరణకు B2B) ఎంచుకుని Import CSV వాడండి.
  4. View Summary నొక్కి, మొత్తాలను మేకర్ టైల్స్‌తో పోల్చండి. టూల్ రేటు, పన్ను విధించదగిన విలువ నుంచి పన్నును లెక్కిస్తుంది; మీ బిల్లులో వేరే మొత్తం ఉంటే పన్ను మొత్తాన్ని సవరించవచ్చు.
  5. ఫైళ్లు మోయలేని వాటిని చేర్చండి: ఎగుమతులకు పోర్ట్ కోడ్, షిప్పింగ్ బిల్; టూల్ ఇంపోర్ట్ చేయకపోతే జారీ చేసిన డాక్యుమెంట్లు, nil-rated టేబుళ్లు (ఈ రెండింటిని చేత్తో టైప్ చేయాల్సి రావచ్చని దాని హెల్ప్ షీట్ చెబుతుంది).
  6. Generate File నొక్కండి. టూల్ మీ కంప్యూటర్‌లో JSON ఫైల్ సేవ్ చేస్తుంది.

GST పోర్టల్‌లో: అప్‌లోడ్ చేసి ఫైల్ చేయండి

  1. లాగిన్ అయి, Services › Returns › Returns Dashboard కి వెళ్లి, సంవత్సరం, కాలాన్ని ఎంచుకోండి.
  2. GSTR-1 టైల్‌లో Prepare Offline, తర్వాత Upload ఎంచుకుని JSON ఫైల్‌ను ఎంచుకోండి. స్టేటస్ processed అని వచ్చే వరకు ఆగండి. ఎర్రర్లు చూపిస్తే ఎర్రర్ ఫైల్‌ను డౌన్‌లోడ్ చేసి, ఆఫ్‌లైన్ టూల్‌లో తెరిచి, సరిచేసి, మళ్ళీ అప్‌లోడ్ చేయండి.
  3. వెనక్కి వచ్చి Prepare Online ఎంచుకుని ప్రతి టేబుల్ చూడండి. IRPలో మీరు నమోదు చేసిన ఇ-ఇన్‌వాయిస్‌లు ఇక్కడ ఇప్పటికే వాటంతట అవే కనిపిస్తాయి.
  4. Generate GSTR-1 Summary నొక్కి, సరిచూసి, తర్వాత DSC లేదా EVC (OTP)తో File Statement చేయండి.

జనం తడబడే చోట్లు

  • ఇ-ఇన్‌వాయిస్‌లు రెండుసార్లు అప్‌లోడ్ కావడం. ఇ-ఇన్‌వాయిసింగ్ వాడితే, ఆ బిల్లులు IRP నుంచి ఇప్పటికే GSTR-1లో ఉన్నాయి. అదే ఇన్‌వాయిస్ నంబర్‌ను మళ్ళీ అప్‌లోడ్ చేస్తే ఎంట్రీ మారిపోతుంది; ఆటోమేటిక్‌గా నిండిన ఎంట్రీలను మళ్ళీ చేర్చకుండా చెక్ చేయండి.
  • తేదీలు. టూల్‌కు DD-MMM-YYYY కావాలి (05-Nov-2026). మేకర్ తేదీలను ఇలాగే రాస్తుంది; Excelలో సవరిస్తే సెల్స్‌ను టెక్స్ట్‌గానే ఉంచండి.
  • రాష్ట్రాలు. సరఫరా స్థలం టూల్ జాబితాలో ఉన్నట్లే "03-Punjab" అని రాయాలి.
  • పాత టెంప్లేట్. ఆఫ్‌లైన్ టూల్ భవిష్యత్ వెర్షన్ కొత్త టెంప్లేట్ అడిగితే, మా వర్క్‌బుక్‌లోని వరుసలను కొత్త టెంప్లేట్‌లో అదే పేర్లున్న షీట్లలోకి కాపీ చేయండి.
  • వేరే సాఫ్ట్‌వేర్‌లో చేసిన బిల్లులు. మేకర్‌కు Nivesh Sahayakలో సేవ్ అయిన బిల్లులు మాత్రమే తెలుసు. JSON తయారుచేసే ముందు మిగతా బిల్లులను ఆఫ్‌లైన్ టూల్‌లో చేర్చండి.
ఈ నెల బిల్లులను ఇప్పుడే GSTR-1లోకి విభజించండి.మేకర్ తెరవండి
